## Visão geral

Esta página traz um **modelo de prompt** para gerar um **reporte de bug** bem estruturado e o **passo a passo** para abrir o Bug no **Azure DevOps**, vinculado ao Pedido (Work Item pai) e com todos os **campos obrigatórios** preenchidos.

A ideia é sempre a mesma: **preencha o prompt → gere o texto → cole o texto no campo "Repro Steps" do Bug → preencha os campos obrigatórios → salve.**

## Como usar (passo a passo)

1. Copie o modelo abaixo e **preencha o que está entre colchetes** com o seu problema.
2. Gere o texto do reporte (com a IA/assistente).
3. No Azure DevOps, a partir do **Pedido**, adicione um **Link filho (Child) do tipo Bug**.
4. **Cole o texto gerado no campo "Repro Steps"** do Bug.
5. Preencha os **campos obrigatórios** (seção abaixo) e **salve**.

## Modelo do prompt

```text
Preciso que você crie um reporte de bug para o Azure DevOps referente ao seguinte problema: [descreva o problema].

Estruture o reporte exatamente nas seções abaixo:

1. Título — resumo curto e objetivo do erro (o quê + onde).
2. Descrição do Erro — o que acontece de errado, em qual tela/módulo, desde quando e com que frequência (sempre / às vezes / em caso específico).
3. Passo a Passo para Reprodução — sequência numerada exata para reproduzir, com dados de exemplo, perfil/usuário e ambiente (HML ou Produção).
4. Comportamento Esperado — o que deveria acontecer se estivesse correto.
5. Possível Ajuste (Sugestão Técnica) — hipótese da causa e sugestão de correção, se houver.
6. Evidência — prints, mensagem de erro, logs, ID do pedido/registro, data e hora.

Escreva de forma clara e objetiva, pronto para colar no Azure DevOps.
```
