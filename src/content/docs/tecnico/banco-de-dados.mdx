## Visão geral

Esta seção reúne assuntos técnicos de **banco de dados e DBA** do S.I.N Implant System: como os dados se estruturam e, principalmente, as tabelas de **De/Para** — os mapeamentos que traduzem os códigos usados no CrmSin para os códigos esperados por outros sistemas (por exemplo, o **SAP S/4HANA**).

## Quando usar esta página

- Entender como um valor cadastrado no sistema é convertido antes de ir para uma integração.
- Apoiar o time de DBA, suporte e integração na conferência de mapeamentos.

<Callout type="info" title="Conteúdo de apoio">
Esta seção é voltada para times responsáveis por configuração, banco de dados, DBA e integração do sistema. Não é necessária para o uso do dia a dia das telas.
</Callout>

## Subpáginas

- **De Para** — tabelas e mapeamentos De/Para entre o CrmSin e o SAP (e o integrador legado RFC/BAPI).
