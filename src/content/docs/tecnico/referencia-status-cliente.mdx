## Visão geral

Esta é uma página de **referência**: a lista completa dos status possíveis do cadastro de cliente, com o significado e a ação típica de suporte. Use-a para consultar rapidamente o que um status quer dizer.

<Callout type="info" title="Dois fluxos de aprovação convivem">
Os status de <strong>Análise/Reanálise/Negado</strong> pertencem ao fluxo <strong>Com Ignition</strong> (legado). Os status <strong>Aguardando Aprovações</strong>, <strong>Ciclo de Aprovação Cancelado</strong> e <strong>Liberado Nova Fila</strong> pertencem ao <strong>novo fluxo de filas</strong>. Qual fluxo vale depende do parâmetro da fila de clientes. Veja os fluxos em <a href="/tecnico/fluxos/cadastro-clientes-sem-ignition">Cadastro de Clientes - Sem Ignition</a> e <a href="/tecnico/fluxos/criacao-de-cliente">Com Ignition</a>.
</Callout>

<Callout type="dica" title="Regra que reabre a aprovação">
Sempre que campos que afetam uma alçada são alterados, o cliente <strong>volta</strong> a aguardar a aprovação daquela alçada. O que define isso é a configuração de <strong>Campo Validação</strong> — detalhada no fluxo <a href="/tecnico/fluxos/cadastro-clientes-sem-ignition">Cadastro de Clientes - Sem Ignition</a>.
</Callout>
