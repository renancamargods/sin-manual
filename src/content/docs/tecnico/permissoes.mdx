## Visão geral

Esta página reúne informações sobre como as permissões controlam o que cada usuário pode ver e fazer no S.I.N Implant System. As permissões são reunidas em perfis de acesso e atribuídas aos usuários.

## Quando usar esta página

- Entender como uma permissão libera o acesso a uma tela ou ação.
- Apoiar a definição de perfis de acesso.
- Consultar as permissões relacionadas a cada rotina.

<Callout type="info" title="Onde configurar">
Os perfis e as permissões dos usuários são gerenciados no módulo Autenticador, pelas telas de Perfil e Usuário.
</Callout>
