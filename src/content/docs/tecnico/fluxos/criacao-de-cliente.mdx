## Visão geral

O fluxo de **Criação e Aprovação de Cliente** descreve o processo completo de cadastro de clientes no sistema, para os tipos **Pessoa Física (PF)**, **Pessoa Jurídica (PJ)** e **Estrangeiro**. O processo vai desde o pré-cadastro, passando pelo preenchimento dos dados, até o envio para as alçadas de aprovação e a integração automática com o SAP quando o cliente é aprovado.

O fluxo acontece no **Módulo Cliente**, principalmente nas telas **Cliente** e **Fila de Aprovações de Cadastro**, e envolve dois tipos de usuário: quem cria o cliente (Master ou Comum) e quem aprova (alçadas de Crédito, Fiscal e Crédito Internacional).

## Quando usar este fluxo

- Cadastrar um novo cliente (PF, PJ ou estrangeiro).
- Enviar um cliente recém-cadastrado para análise das alçadas.
- Aprovar, reprovar ou avaliar um cliente na fila de aprovações.
- Acompanhar o status do cadastro até a ativação e a geração do código SAP.

## Como acessar

- Módulo Cliente → Tela de Cliente
- Módulo Cliente → Fila de Aprovações de Cadastro

## Antes de começar

- Tenha o usuário e a senha do perfil desejado (Master ou Comum).
- Saiba o **tipo de pessoa** (Física, Jurídica ou Estrangeira) e o **tipo de cadastro** (Aluno, Avalista, Estrangeiro, Paciente ou Varejo).
- Tenha em mãos o documento do cliente (CPF ou CNPJ) e os dados obrigatórios (endereço, telefone, e-mail e credencial).

## Passo a passo do processo

### 1. Login e acesso ao Módulo Cliente

1. **Login** — acesse o sistema e informe o usuário e a senha do perfil desejado (Master ou Comum). Clique em **Entrar**.
2. **Novo cadastro** — no menu, vá em **Módulo Cliente → Tela de Cliente** e clique em **"+ Novo Cliente"**. O sistema abre a tela de pré-cadastro.

<Callout type="dica" title="Teste com os dois perfis">
Ao validar o processo, execute os testes tanto com o **Usuário Master** quanto com o **Usuário Comum** (ex.: Consultor), para garantir que as permissões estão corretas.
</Callout>

### 2. Pré-cadastro (integração com o Pulse Credit)

Na tela de pré-cadastro, preencha:

### 4. Envio para análise

1. Clique em **"Enviar Cliente"**.
2. No popup de confirmação, clique em **SIM**.

O cliente é encaminhado para a fila de aprovação conforme o tipo de pessoa:

    ['Estrangeiro', 'Crédito Internacional + Fiscal', 'Alçada de Crédito Internacional (Comex) e alçada Fiscal.'],
  ]}

### 5. Acompanhamento do status

Após o envio, o cliente fica na tela de clientes com o status **"Em Análise pela Área de Cadastro/Crédito"**.

### 6. Aprovação na Fila de Aprovações de Cadastro

1. Faça login com o usuário responsável pela alçada correspondente.
2. Acesse **Módulo Cliente → Fila de Aprovações de Cadastro** e busque o cliente.
3. Escolha uma das ações disponíveis:

- **Aprovar** — aprova o cadastro do cliente.
- **Reprovar** — reprova o cadastro do cliente.
- **Analisar Cliente** — análise detalhada antes de decidir.
- **Enviar para Avaliação** — encaminha para revisão adicional na aba Clientes em Avaliação.
- **Adicionar Observação** — registra uma nota no cadastro.

## Regras e cuidados

- Todos os campos obrigatórios devem ser preenchidos antes de salvar; o botão **"Enviar Cliente"** só fica disponível após salvar com sucesso.
- A alçada de aprovação varia conforme o tipo de pessoa — confira a tabela do envio para análise.
- O código SAP só é gerado na aprovação (status ATIVO).
- Cada perfil deve ter acesso apenas ao necessário para sua função; credenciais de alçada não devem ser compartilhadas.
