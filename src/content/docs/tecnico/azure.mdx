## Visão geral

Esta seção reúne os **padrões e modelos** para abrir itens no **Azure DevOps** de forma consistente: como escrever um **reporte de bug** e como documentar um **requisito de melhoria/desenvolvimento (PBI)**, sempre vinculados ao Pedido e com os campos obrigatórios preenchidos.

## Quando usar esta página

- Abrir um **Bug** bem descrito, com passos de reprodução e evidência.
- Abrir um **PBI** (melhoria ou desenvolvimento) com requisito claro e critérios de aceite.
- Padronizar o que é obrigatório no Azure DevOps antes de salvar o item.

<Callout type="info" title="Conteúdo de apoio">
Esta seção é voltada para quem registra bugs e melhorias no Azure DevOps. Use os modelos de prompt para gerar o texto e siga o passo a passo de abertura em cada submódulo.
</Callout>

## Submódulos

- **[Abertura de BUG](/tecnico/azure/abertura-de-bug)** — modelo de prompt para o reporte de bug e passo a passo de abertura no Azure DevOps (o texto vai em "Repro Steps").
- **[Abertura de Melhoria / Desenvolvimento (PBI)](/tecnico/azure/abertura-de-melhoria-pbi)** — modelo de prompt para a documentação de requisito e passo a passo de abertura do PBI (o texto vai em "Description").
