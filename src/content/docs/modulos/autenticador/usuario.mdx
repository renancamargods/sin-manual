## Visão geral

A tela **Usuário** reúne o cadastro das pessoas que acessam o S.I.N Implant System, associando cada uma a um perfil de acesso, um departamento e, quando aplicável, um ou mais grupos.

É por meio deste cadastro que se define quem pode entrar no sistema e, em conjunto com o Perfil, o que cada pessoa pode ver e fazer.

## Quando usar esta tela

- Cadastrar um novo usuário.
- Consultar os dados de acesso de um usuário existente.
- Alterar o perfil, o departamento ou o grupo de um usuário.
- Bloquear ou inativar o acesso de um usuário.

## Como acessar

Autenticador → Usuário

## Antes de começar

- Confirme o perfil de acesso adequado para a função da pessoa.
- Verifique se a pessoa já não possui cadastro de usuário.
- Tenha em mãos o e-mail corporativo válido, usado para login e recuperação de senha.

## Fluxos principais

1. **Cadastrar novo usuário** — preencha os dados obrigatórios, associe um perfil e salve.
2. **Consultar usuário** — utilize a busca para localizar pelo nome ou e-mail.
3. **Alterar usuário** — atualize perfil, departamento ou grupo conforme necessário.
4. **Inativar usuário** — altere a situação para inativo quando a pessoa deixar de precisar de acesso.

## Relações com outros cadastros ou processos

Este cadastro depende de um perfil já configurado na tela Perfil e pode ser organizado por departamento e grupo. O histórico de acessos pode ser consultado na tela Tentativa de Login.

## Parâmetros e comportamentos importantes

- O usuário precisa estar ativo para conseguir acessar o sistema.
- A alteração de perfil passa a valer no próximo acesso do usuário.
- Usuários inativos não conseguem realizar login, mas seu histórico é mantido.

## Regras e cuidados

- Cadastre apenas pessoas autorizadas pela empresa.
- Evite duplicar cadastros para a mesma pessoa.
- Prefira inativar em vez de excluir um usuário que já tenha histórico de uso.
- Revise o perfil atribuído sempre que a função da pessoa mudar.
