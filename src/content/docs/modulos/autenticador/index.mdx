## Visão geral

O módulo **Autenticador** controla quem acessa o sistema e o que cada pessoa pode fazer. Aqui ficam os cadastros de usuários, perfis de acesso, grupos e o histórico de tentativas de login.

## Quando usar este módulo

- Cadastrar ou alterar um usuário.
- Configurar um perfil de acesso e suas permissões.
- Consultar tentativas de login.
- Organizar usuários por departamento ou grupo.

## Como acessar

Menu lateral → Módulos → Autenticador

<Callout type="cuidado" title="Impacto amplo">
Alterações neste módulo afetam diretamente o que outros usuários conseguem ver e fazer no sistema. Revise com atenção antes de salvar.
</Callout>
