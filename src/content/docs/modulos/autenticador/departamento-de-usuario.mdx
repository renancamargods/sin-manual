## Visão geral

A tela **Departamento de Usuário** reúne o cadastro dos **departamentos** que agrupam os usuários por **área da empresa**. Cada departamento é vinculado a uma **diretoria**.

  cards={[

  ]}
/>

## Quando usar esta tela

- Cadastrar um novo departamento.
- Consultar os departamentos já cadastrados.
- Alterar a diretoria de um departamento.

## Como acessar

Autenticador → Departamento de Usuário
