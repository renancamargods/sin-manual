## Visão geral

A tela **Módulo** reúne o cadastro dos **módulos** disponíveis no sistema. Cada módulo tem um **nome** e uma **exibição na barra de endereços** (o texto usado na URL do módulo).

## Quando usar esta tela

- Cadastrar um novo módulo.
- Consultar os módulos já cadastrados.
- Ajustar o nome ou a exibição na barra de endereços de um módulo.

## Como acessar

Autenticador → Módulo
