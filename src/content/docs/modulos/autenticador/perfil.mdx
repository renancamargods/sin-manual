## Visão geral

A tela **Perfil** reúne o cadastro dos **perfis de acesso** (ex.: "Administrador", "Consultor FVE", "Coordenador"). Cada perfil tem um **título** e reúne um ou mais **grupos** de permissões, que definem o que o usuário pode acessar no sistema.

## Quando usar esta tela

- Cadastrar um novo perfil de acesso.
- Consultar os perfis já cadastrados.
- Alterar os grupos associados a um perfil.

## Como acessar

Autenticador → Perfil

## Relação com outros processos

- **Grupo** — os perfis reúnem os grupos de permissões.
- **Usuário** — o perfil é atribuído ao usuário para definir seu acesso.

## O que a tela não faz

- Não cadastra os usuários — apenas os perfis; os usuários são cadastrados na tela Usuário.
