## Visão geral

O módulo **Planejamento de Vendas** apoia a definição de metas e volumes esperados de venda, servindo de referência para acompanhamento comercial.

## Quando usar este módulo

- Cadastrar um novo planejamento de vendas.
- Consultar metas definidas para um período.

## Como acessar

Menu lateral → Módulos → Planejamento de Vendas

<Callout type="info" title="Uso comparativo">
O planejamento cadastrado aqui costuma ser usado como referência para comparar com o volume de vendas realizado.
</Callout>
