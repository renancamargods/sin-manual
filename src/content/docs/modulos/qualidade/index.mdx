## Visão geral

O módulo **Qualidade** reúne o registro e o acompanhamento das análises de qualidade realizadas sobre os produtos.

## Quando usar este módulo

- Registrar uma nova análise de qualidade.
- Consultar o resultado de análises já realizadas.

## Como acessar

Menu lateral → Módulos → Qualidade

<Callout type="info" title="Relação com Produtos">
As análises registradas aqui ficam vinculadas ao cadastro do produto correspondente.
</Callout>
