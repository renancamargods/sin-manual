## Visão geral

O módulo **Contratos** reúne o cadastro e o acompanhamento de contratos comerciais firmados com os clientes, incluindo metas de consumo e políticas específicas aplicadas a cada contrato.

## Quando usar este módulo

- Cadastrar um novo contrato.
- Acompanhar metas de consumo previstas.
- Consultar anexos e políticas vinculadas ao contrato.

## Como acessar

Menu lateral → Módulos → Contratos

<Callout type="info" title="Relação com clientes">
Um contrato está sempre vinculado a um cliente cadastrado no módulo Clientes.
</Callout>
