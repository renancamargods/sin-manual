## Visão geral

A tela **Tipo Incidência** reúne o cadastro dos **tipos de incidência** usados para **classificar as ocorrências**. Cada tipo tem uma descrição, um **embasamento de não procedência** e um campo de **outras informações**.

  ]}
/>

## Quando usar esta tela

- Cadastrar um novo tipo de incidência.
- Consultar os tipos já cadastrados.
- Ajustar o embasamento ou as informações de um tipo.

## Como acessar

Ocorrências → Tipo Incidência
