## Visão geral

A tela **Pesquisas** é um **construtor de pesquisas (questionários)**. Cada pesquisa tem um **título**, um **slug** (identificador único gerado a partir do título) e a marcação **Ativo**, além de **seções** que organizam as perguntas. A tela também permite consultar as **respostas** e, a partir de uma resposta, **gerar uma Ocorrência PFCQ**.

## Quando usar esta tela

- Criar uma nova pesquisa (questionário).
- Adicionar seções e perguntas a uma pesquisa.
- Consultar as respostas de uma pesquisa.
- Gerar uma Ocorrência PFCQ a partir de uma resposta.

## Como acessar

Ocorrências → Pesquisas

## Fluxos principais

1. **Criar** — clique em **"+ Novo"**, informe o "Título", ajuste o "Slug" e marque "Ativo".
2. **Montar** — em "Seções", clique em **"+ Nova seção"** e adicione as perguntas.
3. **Salvar** — clique em **"Salvar"**.
4. **Consultar respostas** — abra a aba **"Respostas"**.
5. **Gerar ocorrência** — use o botão **"Gerar Ocorrência PFCQ"** para abrir uma ocorrência a partir da pesquisa/resposta.

## Relação com outros processos

- **Ocorrências PFCQ** — o botão "Gerar Ocorrência PFCQ" cria uma ocorrência a partir da pesquisa.

## O que a tela não faz

- Não trata a ocorrência — apenas a gera; o tratamento acontece na tela Ocorrências PFCQ.
