## Visão geral

A tela **Tipo de Campo** reúne o cadastro dos **tipos de campo** disponíveis para os formulários do roteirizador. Cada tipo tem uma **descrição** e é usado ao definir os campos de um formulário.

  cards={[

    { label: 'Cuidado', title: 'Descrição clara', text: 'Use uma descrição clara para identificar o tipo.' },
  ]}
/>

## Quando usar esta tela

- Cadastrar um novo tipo de campo.
- Consultar os tipos já cadastrados.

## Como acessar

Roteirizador → Tipo de Campo
