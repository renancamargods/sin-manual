## Visão geral

A tela **Tipo de Agenda** reúne o cadastro dos **tipos de agenda** usados para **classificar os atendimentos** do roteirizador. Cada tipo tem uma **descrição** e a indicação de se é uma **visita**.

  ]}
/>

## Quando usar esta tela

- Cadastrar um novo tipo de agenda.
- Consultar os tipos já cadastrados.

## Como acessar

Roteirizador → Tipo de Agenda
