## Visão geral

A tela **Formulário** reúne o cadastro dos **formulários** usados em campo. Cada formulário tem uma **descrição** e reúne, em uma aba, os **campos** que o compõem (aba "Campo do Formulário"). Os formulários são preenchidos durante os atendimentos.

## Quando usar esta tela

- Cadastrar um novo formulário.
- Consultar os formulários já cadastrados.
- Montar ou ajustar os campos de um formulário.

## Como acessar

Roteirizador → Formulário
