## Visão geral

O módulo **Simulador** reúne **treinos guiados passo a passo** das telas do sistema. Cada treino é um ambiente de prática onde você percorre uma rotina do começo ao fim — do pré-cadastro à conclusão — com o **Dentinho** explicando cada etapa e mostrando o **porquê** de cada bloqueio.

## Quando usar este módulo

- Aprender uma tela na prática, sem medo de errar.
- Treinar um usuário novo antes de ele mexer no sistema real.
- Entender as regras (campos obrigatórios, alçadas, status) de forma interativa.

## Como acessar

Menu lateral → Módulos → Simulador

<Callout type="dica" title="🦷 É só treino">
Nada do que você faz no simulador é salvo no sistema. É um ambiente de prática — pode clicar à vontade, voltar e recomeçar quantas vezes quiser.
</Callout>
