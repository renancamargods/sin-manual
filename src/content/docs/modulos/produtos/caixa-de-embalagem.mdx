## Visão geral

A tela **Caixa de Embalagem** mantém o cadastro das **caixas** usadas para embalar os produtos. Cada caixa é identificada por um **código** e tem um **volume**, usados na expedição e no cálculo de volumes das remessas.

## Quando usar esta tela

- Consultar as caixas de embalagem cadastradas.
- Incluir uma nova caixa.
- Corrigir o código ou o volume de uma caixa.

## Como acessar

Produtos → Caixa de Embalagem

## Antes de começar

- Tenha o **código** e o **volume** da caixa.
- Confirme que o seu perfil permite manter este cadastro.

## O que a tela não faz

- Não cadastra os produtos — apenas as caixas de embalagem.
- Não calcula o frete — apenas mantém o volume da caixa.
