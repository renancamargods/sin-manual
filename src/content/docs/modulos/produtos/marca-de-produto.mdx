## Visão geral

A tela **Marca de Produto** mantém as **marcas** associadas aos produtos (ex.: "SIN", "Singular"). Cada marca tem um **código** e uma **descrição**, e ajuda a classificar os produtos.

## Quando usar esta tela

- Consultar as marcas cadastradas.
- Incluir uma nova marca.
- Corrigir o código ou a descrição de uma marca.

## Como acessar

Produtos → Marca de Produto

## Antes de começar

- Tenha o **código** e a **descrição** da marca.
- Confirme que o seu perfil permite manter este cadastro.

- Não classifica os produtos automaticamente — apenas mantém a lista de marcas.
