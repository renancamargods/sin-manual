## Visão geral

O módulo **Produtos** centraliza o cadastro dos produtos comercializados, incluindo hierarquia, embalagens, impostos, imagens e saldo de estoque.

## Quando usar este módulo

- Cadastrar um novo produto.
- Consultar ou alterar dados do produto.
- Organizar produtos por família, marca ou hierarquia.
- Consultar o saldo de estoque disponível.

## Como acessar

Menu lateral → Módulos → Produtos

<Callout type="cuidado" title="Uso em outros módulos">
O cadastro do produto é utilizado em pedidos, faturamento, regulatórios e qualidade. Mantenha as informações sempre atualizadas.
</Callout>
