## Visão geral

A tela **Produto** centraliza o cadastro dos produtos comercializados pela empresa, incluindo dados de identificação, hierarquia, embalagem e informações usadas por outros módulos, como regulatório e qualidade.

Um cadastro de produto completo é essencial para que pedidos, faturamento e controles regulatórios funcionem corretamente.

## Quando usar esta tela

- Cadastrar um novo produto.
- Consultar informações de um produto já cadastrado.
- Alterar dados de identificação, hierarquia ou embalagem.
- Consultar o saldo de estoque disponível para o produto.

## Como acessar

Produtos → Produto

## Antes de começar

- Confirme a família, o grupo e a hierarquia corretos para o novo produto.
- Verifique se o produto já não está cadastrado, para evitar duplicidade.
- Tenha em mãos as informações de embalagem, código de barras (GTIN) e imagens, se disponíveis.

## Fluxos principais

1. **Cadastrar novo produto** — preencha os dados obrigatórios e salve o cadastro.
2. **Consultar produto** — utilize a busca para localizar pelo código ou descrição.
3. **Alterar produto** — abra o cadastro, atualize os campos necessários e salve.
4. **Consultar saldo de estoque** — acesse a informação de estoque disponível para o produto.

## Relações com outros cadastros ou processos

Este cadastro pode ser usado em pedidos, faturamento, inventários, qualidade e registros regulatórios. Alterações na hierarquia ou classificação do produto podem impactar relatórios que utilizam esse agrupamento.

## Parâmetros e comportamentos importantes

- O produto precisa estar ativo para ser usado em novos pedidos.
- Alterações no cadastro passam a valer para novas operações.
- Alguns campos podem aparecer conforme a linha regulatória do produto.

## Regras e cuidados

- Revise os dados antes de gravar o cadastro.
- Evite cadastrar o mesmo produto mais de uma vez; utilize a busca antes de criar um novo registro.
- Prefira inativar o produto em vez de excluí-lo quando já houver uso em pedidos ou estoque.
- Verifique suas permissões antes de alterar dados do produto.
