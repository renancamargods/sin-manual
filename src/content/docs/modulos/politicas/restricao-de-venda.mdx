## Visão geral

A tela **Restrição de Venda** reúne o cadastro das **restrições** aplicadas a determinadas vendas. Cada restrição tem um **tipo**, uma **vigência** e uma **segmentação** (cliente, lounge, estado, ramo de atividade, canal, tipo de pedido, grupo de usuário) que define onde a restrição se aplica.

## Quando usar esta tela

- Cadastrar uma nova restrição de venda.
- Consultar as restrições já cadastradas.
- Ajustar o tipo, a vigência ou a segmentação de uma restrição.

## Como acessar

Políticas → Restrição de Venda
