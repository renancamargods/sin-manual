## Visão geral

A tela **Premiação Condicionada** reúne o cadastro das **premiações** vinculadas a condições/metas. Cada premiação tem uma **forma de aplicação**, uma **faixa de valores** (mínimo e máximo), uma **vigência** e a relação de **participantes** (aba "Participação em Premiações").

## Quando usar esta tela

- Cadastrar uma nova premiação condicionada.
- Consultar as premiações já cadastradas.
- Gerenciar os participantes de uma premiação.

## Como acessar

Políticas → Premiação Condicionada
