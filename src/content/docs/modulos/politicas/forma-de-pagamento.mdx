## Visão geral

A tela **Forma de Pagamento** reúne o cadastro das **formas de pagamento** aceitas nas operações. Cada forma tem uma descrição, uma observação e a indicação de **disponibilidade para Comex**, além de reunir, em uma aba, as **condições de pagamento** vinculadas.

## Quando usar esta tela

- Cadastrar uma nova forma de pagamento.
- Consultar as formas já cadastradas.
- Consultar as condições de pagamento vinculadas a uma forma.

## Como acessar

Políticas → Forma de Pagamento
