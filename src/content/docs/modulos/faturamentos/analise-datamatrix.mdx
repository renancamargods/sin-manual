## Visão geral

A tela **Análise DataMatrix** é uma ferramenta de **conferência** dos códigos **DataMatrix** dos produtos. Ela permite informar um ou vários itens — por **bipagem** (leitura), por **cópia e cola** dos códigos ou a partir de uma **nota fiscal** — e ver os dados que cada DataMatrix carrega (como produto, lote e serial), montando uma lista que pode ser **exportada para Excel**.

É uma tela de **consulta**: não cria, não fatura e não altera pedidos ou remessas. Serve para analisar e validar os códigos lidos.

## Quando usar esta tela

- Conferir se um DataMatrix está legível e íntegro.
- Analisar os dados que um código carrega (produto, lote, serial).
- Verificar vários itens de uma vez, por bipagem ou colando os códigos.
- Levantar os itens de uma nota fiscal para conferência.
- Exportar a lista conferida para Excel.

## Como acessar

Faturamentos → Análise DataMatrix

## Antes de começar

- Tenha os produtos com o **DataMatrix** legível para bipar, ou os códigos para colar.
- Para a consulta por nota fiscal, tenha a **empresa** e a **nota fiscal** de referência.
- Confirme que o seu perfil tem acesso à tela.

## O que a tela não faz

- Não fatura e não gera pedidos ou remessas.
- Não altera notas fiscais nem cadastros de produtos.
- Não movimenta estoque — apenas confere os códigos informados.
