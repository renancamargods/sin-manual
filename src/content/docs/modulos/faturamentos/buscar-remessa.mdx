## Visão geral

A tela **Buscar Remessa** é uma ferramenta de **consulta** do módulo de Faturamentos, usada para **localizar remessas** a partir dos seus identificadores. É o ponto de partida para encontrar uma remessa específica e seguir para as demais rotinas de expedição e faturamento.

## Quando usar esta tela

- Localizar uma remessa específica do faturamento.
- Consultar remessas a partir dos seus identificadores.
- Encontrar a remessa como ponto de partida para outras rotinas do módulo.

## Como acessar

Faturamentos → Buscar Remessa

## Antes de começar

- Tenha em mãos os dados que identificam a remessa que deseja localizar.
- Confirme que o seu perfil tem acesso à tela.

## O que a tela não faz

- Não fatura pedidos nem gera remessas — apenas as localiza.
- Não altera os dados das remessas encontradas.
