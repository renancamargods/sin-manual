## Visão geral

A tela **Log Análise de Pedido** permite consultar o histórico das análises automáticas aplicadas aos pedidos. Para cada execução, o log mostra o **Número do Pedido**, o **Código do Cliente**, a **Regra Aplicada**, o **Motivo** e o **Resultado**, com a **Data de Execução**.

<Callout type="info" title="Tela de consulta">
Esta é uma tela de consulta (log). Ela registra o que o sistema fez na análise dos pedidos, servindo para rastreabilidade.
</Callout>

## Quando usar esta tela

- Consultar quais regras foram aplicadas na análise de um pedido.
- Verificar o motivo e o resultado de uma análise.

## Como acessar

Pedidos → Log Análise de Pedido

## Antes de começar

- Tenha, se necessário, o **Número do Pedido**, o **Código do Cliente** ou a **Regra Aplicada** para filtrar.

## Fluxos principais

1. **Consultar** — informe os filtros (Número do Pedido, Código do Cliente, Regra Aplicada) e clique em **"Pesquisar"**.
2. **Analisar** — verifique a regra aplicada, o motivo e o resultado de cada execução.
