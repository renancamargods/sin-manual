## Visão geral

A tela **Notas Fiscais - XML** permite consultar e **baixar os arquivos XML** das notas fiscais. Você filtra por diversos critérios (cliente, período, CFOP, natureza de operação, transportadora, valor) e usa a ação **"Gerar arquivo zip e fazer download"** para baixar os XMLs selecionados.

<Callout type="info" title="Tela de consulta e download">
Esta tela é usada para localizar notas e baixar seus XMLs em um arquivo zip. Não emite nem altera notas.
</Callout>

## Quando usar esta tela

- Baixar os XMLs de notas fiscais de um período ou cliente.
- Filtrar notas por CFOP, natureza de operação, transportadora ou valor.

## Como acessar

Pedidos → Notas Fiscais - XML

## Antes de começar

- Defina os filtros (cliente, período, CFOP, natureza de operação, transportadora, valor).

## Fluxos principais

1. **Consultar** — informe os filtros e clique em **"Pesquisar"**.
2. **Selecionar** — marque as notas desejadas (ou use **"Selecionar todos"**).
3. **Baixar** — clique em **"Gerar arquivo zip e fazer download"** para baixar os XMLs.
