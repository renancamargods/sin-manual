## Visão geral

O módulo **Aprovações** define quais informações precisam passar por aprovação antes de seguir em outros processos, e quem é responsável por aprovar cada situação. Ele é usado em conjunto com outros módulos, como Pedidos e Contratos.

## Quando usar este módulo

- Definir o que precisa de aprovação.
- Configurar quem aprova cada tipo de solicitação.
- Consultar as regras de aprovação já cadastradas.

## Como acessar

Menu lateral → Módulos → Aprovações

<Callout type="info" title="Uso combinado">
As regras cadastradas aqui passam a valer para os processos de outros módulos que utilizam aprovação, como pedidos e contratos.
</Callout>
