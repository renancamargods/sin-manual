## Visão geral

A tela **Nova Fila de Aprovação - Clientes** é onde os grupos responsáveis **decidem sobre os cadastros de clientes** que foram enviados para aprovação. Nela, cada cliente que aguarda liberação aparece em uma lista, com o seu status, o andamento do ciclo e as ações para **aprovar**, **reprovar** ou **enviar para avaliação**.

É a fila que recebe os clientes enviados pela tela **Cliente**. Enquanto a tela de Cliente cria e encaminha o cadastro, é aqui que as alçadas registram a decisão que faz o cliente avançar (ou voltar) no ciclo de aprovação.

A tela organiza o trabalho em duas abas: **"Clientes a Liberar"** (aguardando a decisão) e **"Clientes em Avaliação"** (enviados para avaliação). Consulte também o [Fluxo de Criação e Aprovação de Cliente](/tecnico/fluxos/criacao-de-cliente).

## Quando usar esta tela

- Consultar os clientes que aguardam a sua aprovação.
- Aprovar um cliente para que ele avance no ciclo de aprovação.
- Reprovar um cadastro que não atende aos requisitos.
- Enviar um cliente para avaliação quando for preciso uma análise antes de decidir.
- Acompanhar a quantidade de clientes na fila e o andamento de cada um.

## Como acessar

Aprovações → Nova Fila de Aprovação - Clientes

## Antes de começar

- Confirme que o seu grupo é responsável pela etapa do ciclo desses clientes.
- Tenha em mãos o critério de análise (cadastro, crédito, fiscal, conforme a alçada).
- Se for reprovar, saiba o motivo — ele orienta o consultor a corrigir o cadastro.

## Fluxos principais

1. **Localizar o cliente** — informe os filtros (Cliente, Tipo de Pessoa, Empresas) e clique em **"Atualizar"**.
2. **Escolher a aba** — use **"Clientes a Liberar"** para os que aguardam decisão ou **"Clientes em Avaliação"** para os que foram enviados para avaliação.
3. **Conferir o cadastro** — use o ícone de edição/visualização da linha para revisar os dados antes de decidir.
4. **Decidir** — na linha do cliente, use **Aprovar**, **Reprovar** ou **Enviar para avaliação**, conforme a análise.
5. **Acompanhar** — os totalizadores e o status de cada linha mostram o andamento; ao decidir, o cliente segue no ciclo.

## O que a tela não faz

- Não cria nem envia clientes — isso é feito na tela de Cliente.
- Não gera o código SAP — ele é criado quando o cliente é ativado após a aprovação.
- Não altera as regras de aprovação nem define quem são as alçadas.
