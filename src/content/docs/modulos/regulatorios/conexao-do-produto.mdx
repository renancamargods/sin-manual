## Visão geral

A tela **Conexão do Produto** mantém a lista das **conexões** associadas aos produtos — por exemplo, "CM" (Cone Morse), "HE" (Hexágono Externo) e "HI" (Hexágono Interno). A conexão é usada na **classificação** dos implantes, inclusive para fins regulatórios.

## Quando usar esta tela

- Consultar as conexões cadastradas.
- Incluir uma nova conexão.
- Corrigir a descrição de uma conexão.

## Como acessar

Regulatórios → Conexão do Produto

## Antes de começar

- Tenha a **descrição** da conexão.
- Confirme que o seu perfil permite manter este cadastro.
