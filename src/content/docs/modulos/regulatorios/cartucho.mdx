## Visão geral

A tela **Cartucho** mantém o cadastro dos **cartuchos** relacionados aos produtos, identificados pelo **código do cartucho** (ex.: "EC0007"). Os cartuchos são usados no processo de **encartuchamento** e na rastreabilidade regulatória.

## Quando usar esta tela

- Consultar os cartuchos cadastrados.
- Incluir um novo cartucho.
- Corrigir o código de um cartucho.

## Como acessar

Regulatórios → Cartucho

## Antes de começar

- Tenha o **código** do cartucho.
- Confirme que o seu perfil permite manter este cadastro.
