## Visão geral

A tela **Tipo do Material de Produção** mantém a lista dos **tipos de material** usados na **produção** dos produtos. Cada tipo é identificado por uma **descrição** e é usado para fins de classificação regulatória (por exemplo, o material do dispositivo).

## Quando usar esta tela

- Consultar os tipos de material de produção cadastrados.
- Incluir um novo tipo.
- Corrigir a descrição de um tipo.

## Como acessar

Regulatórios → Tipo do Material de Produção

## Antes de começar

- Tenha a **descrição** do tipo de material.
- Confirme que o seu perfil permite manter este cadastro.
