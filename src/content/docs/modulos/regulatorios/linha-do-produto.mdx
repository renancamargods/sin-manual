## Visão geral

A tela **Linha do Produto** mantém as **linhas regulatórias** associadas aos produtos. Cada linha é identificada pela sua **descrição** e apoia a classificação regulatória dos produtos.

## Quando usar esta tela

- Consultar as linhas regulatórias cadastradas.
- Incluir uma nova linha.
- Corrigir a descrição de uma linha.

## Como acessar

Regulatórios → Linha do Produto

## Antes de começar

- Tenha a **descrição** da linha.
- Confirme que o seu perfil permite manter este cadastro.
