## Visão geral

A tela **Etiqueta Emblistadora** mantém os **modelos de etiqueta** usados na **emblistadora** (equipamento de embalagem em blister). Cada modelo é identificado por uma **descrição** e é usado na geração das etiquetas no processo de emblistamento.

## Quando usar esta tela

- Consultar os modelos de etiqueta da emblistadora.
- Incluir um novo modelo.
- Corrigir a descrição de um modelo.

## Como acessar

Regulatórios → Etiqueta Emblistadora

## Antes de começar

- Tenha a **descrição** do modelo de etiqueta.
- Confirme que o seu perfil permite manter este cadastro.
