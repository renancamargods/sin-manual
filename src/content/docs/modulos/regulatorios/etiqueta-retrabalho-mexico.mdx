## Visão geral

A tela **Etiqueta Retrabalho México** mantém os **modelos de etiqueta de retrabalho** específicos para o **México**. Cada modelo é identificado por uma **descrição** e é usado na readequação (retrabalho) das etiquetas dos produtos conforme as exigências regulatórias desse mercado.

## Quando usar esta tela

- Consultar os modelos de etiqueta de retrabalho do México.
- Incluir um novo modelo.
- Corrigir a descrição de um modelo.

## Como acessar

Regulatórios → Etiqueta Retrabalho México

## Antes de começar

- Tenha a **descrição** do modelo de etiqueta.
- Confirme que o seu perfil permite manter este cadastro.
