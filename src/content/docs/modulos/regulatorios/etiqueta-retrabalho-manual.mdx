## Visão geral

A tela **Etiqueta Retrabalho Manual** mantém os **modelos de etiqueta de retrabalho gerados manualmente** (ex.: "EE0034_KIT_A_REV03", "EE0044_COMP_NEST_C"). Cada modelo é identificado por uma **descrição** e é usado no retrabalho manual das etiquetas dos produtos.

## Quando usar esta tela

- Consultar os modelos de etiqueta de retrabalho manual.
- Incluir um novo modelo.
- Corrigir a descrição de um modelo.

## Como acessar

Regulatórios → Etiqueta Retrabalho Manual

## Antes de começar

- Tenha a **descrição** do modelo de etiqueta.
- Confirme que o seu perfil permite manter este cadastro.
