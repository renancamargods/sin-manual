## Visão geral

A tela **Registros** mantém os **registros regulatórios** dos produtos por **país** e **agência reguladora**. Cada registro guarda o **número do registro**, a **classe de risco**, o **listing number** e o **device ID**, servindo de base para o controle regulatório dos produtos.

## Quando usar esta tela

- Cadastrar o registro regulatório de um produto em um país/agência.
- Consultar os registros por classe de risco, número ou device ID.
- Corrigir os dados de um registro.

## Como acessar

Regulatórios → Registros

## Antes de começar

- Tenha o **país**, a **agência reguladora** e o **número do registro**.
- Saiba a **classe de risco** e os identificadores (listing number, device ID).
- Confirme que o seu perfil permite manter este cadastro.

## O que a tela não faz

- Não emite o registro na agência — apenas guarda os dados do registro.
- Não cadastra o produto base.
