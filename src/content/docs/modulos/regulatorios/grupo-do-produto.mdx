## Visão geral

A tela **Grupo do Produto** (no módulo Regulatórios) mantém os **grupos regulatórios** usados para classificar os produtos sob o ponto de vista regulatório. Cada grupo é identificado pela sua **descrição**.

<Callout type="info" title="Não confundir com o Grupo de Produto (módulo Produtos)">
Existe também um **Grupo de Produto** no módulo **Produtos** (classificação comercial). Este **Grupo do Produto** é do módulo **Regulatórios** e tem finalidade regulatória.
</Callout>

## Quando usar esta tela

- Consultar os grupos regulatórios cadastrados.
- Incluir um novo grupo.
- Corrigir a descrição de um grupo.

## Como acessar

Regulatórios → Grupo do Produto

## Antes de começar

- Tenha a **descrição** do grupo.
- Confirme que o seu perfil permite manter este cadastro.
