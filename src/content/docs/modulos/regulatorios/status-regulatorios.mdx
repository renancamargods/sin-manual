## Visão geral

A tela **Status Regulatórios** mantém a lista dos **status** usados para indicar a **situação regulatória** atual dos produtos. Cada status é identificado por uma **descrição** e é aplicado aos produtos para acompanhar a sua situação perante os órgãos reguladores.

## Quando usar esta tela

- Consultar os status regulatórios cadastrados.
- Incluir um novo status.
- Corrigir a descrição de um status.

## Como acessar

Regulatórios → Status Regulatórios

## Antes de começar

- Tenha a **descrição** do status.
- Confirme que o seu perfil permite manter este cadastro.

## O que a tela não faz

- Não altera a situação real do produto perante o órgão — apenas mantém a lista de status.
