## Visão geral

A tela **Marcação CE** controla a **marcação CE** (conformidade europeia) aplicável aos produtos. Cada registro é identificado por uma **descrição** e é usado no controle regulatório dos produtos destinados ao mercado europeu.

## Quando usar esta tela

- Consultar os registros de marcação CE.
- Incluir um novo registro.
- Corrigir a descrição de um registro.

## Como acessar

Regulatórios → Marcação CE

## Antes de começar

- Tenha a **descrição** do registro de marcação CE.
- Confirme que o seu perfil permite manter este cadastro.
