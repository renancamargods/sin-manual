## Visão geral

A tela **Line Arábia Saudita** mantém a **configuração regulatória de linha** específica para a **Arábia Saudita**. Cada registro é identificado por uma **descrição** e apoia a adequação regulatória dos produtos para esse mercado.

## Quando usar esta tela

- Consultar os registros de line da Arábia Saudita.
- Incluir um novo registro.
- Corrigir a descrição de um registro.

## Como acessar

Regulatórios → Line Arábia Saudita

## Antes de começar

- Tenha a **descrição** do registro.
- Confirme que o seu perfil permite manter este cadastro.
