## Visão geral

A tela **Atividade Econômica** mantém a lista das **atividades econômicas** (no padrão **CNAE**) usadas para **classificar os clientes**. Cada atividade tem um **código** (ex.: "0111-3/01") e uma **descrição** (ex.: "Cultivo de arroz").

## Quando usar esta tela

- Consultar as atividades econômicas cadastradas.
- Incluir uma nova atividade econômica.
- Corrigir o código ou a descrição de uma atividade.

## Como acessar

Clientes → Atividade Econômica

## Antes de começar

- Tenha o **código CNAE** e a **descrição** da atividade.
- Confirme que o seu perfil permite manter este cadastro.

## O que a tela não faz

- Não classifica os clientes automaticamente — apenas mantém a lista de atividades.
- Não altera dados fiscais do cliente.
