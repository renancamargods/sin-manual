## Visão geral

A tela **Cliente** centraliza os dados cadastrais, comerciais e fiscais de cada cliente da empresa. É a partir deste cadastro que outras rotinas — como pedidos, contratos e faturamento — identificam e aplicam as informações corretas para cada cliente.

Manter este cadastro completo e atualizado evita retrabalho e problemas em processos posteriores, como emissão de nota fiscal e aplicação de políticas comerciais.

## Quando usar esta tela

- Cadastrar um novo cliente.
- Consultar dados comerciais e fiscais de um cliente já cadastrado.
- Alterar informações de contato, endereço ou dados fiscais.
- Acompanhar a situação (ativo ou inativo) de um cliente.

## Como acessar

Clientes → Cliente

## Antes de começar

- Tenha em mãos os documentos e dados fiscais do cliente (CNPJ ou CPF, inscrição estadual, endereço).
- Verifique se o cliente já não possui cadastro, para evitar duplicidade.
- Confirme com o time comercial a classificação e o canal corretos para o cliente.

## Fluxos principais

1. **Cadastrar novo cliente** — preencha os dados obrigatórios e salve o cadastro.
2. **Consultar cliente** — utilize a busca para localizar pelo nome, código ou documento.
3. **Alterar cliente** — abra o cadastro, atualize os campos necessários e salve.
4. **Inativar cliente** — altere a situação para inativo quando o cliente não estiver mais em operação.

## Relações com outros cadastros ou processos

Este cadastro pode ser usado em pedidos, contratos, políticas comerciais e faturamento. Alterações nos dados fiscais do cliente podem impactar a emissão de notas fiscais futuras.

## Parâmetros e comportamentos importantes

- O cadastro precisa estar ativo para ser usado em novos pedidos.
- Alterações nos dados fiscais passam a valer para novas operações, sem alterar documentos já emitidos.
- Alguns campos podem variar conforme o país ou o regime tributário do cliente.

## Regras e cuidados

- Revise os dados fiscais antes de gravar o cadastro.
- Evite cadastrar o mesmo cliente mais de uma vez; utilize a busca antes de criar um novo registro.
- Prefira inativar o cadastro em vez de excluí-lo quando já houver pedidos ou contratos vinculados.
- Verifique suas permissões antes de tentar alterar dados fiscais.
