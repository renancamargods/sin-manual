## Visão geral

A tela **Cliente** é onde os clientes são cadastrados no sistema, nos tipos **Pessoa Física (PF)**, **Pessoa Jurídica (PJ)** e **Estrangeiro**. A partir dela, o cliente é preenchido, salvo e enviado para a análise das alçadas de aprovação.

O cadastro começa por um **pré-cadastro** (integração com o Pulse Credit) e segue para o **cadastro completo**, com os dados obrigatórios. Depois de salvo, o cliente pode ser enviado para aprovação; quando aprovado, passa a **ATIVO** e recebe o **código SAP** automaticamente.

Esta tela é o ponto de partida do [Fluxo de Criação e Aprovação de Cliente](/tecnico/fluxos/criacao-de-cliente).

## Quando usar esta tela

- Cadastrar um novo cliente (PF, PJ ou estrangeiro).
- Consultar ou alterar os dados de um cliente.
- Enviar um cliente para a análise das alçadas de aprovação.
- Acompanhar o status do cadastro até a ativação.

## Como acessar

Módulo Cliente → Tela de Cliente

## Antes de começar

- Tenha o documento do cliente (CPF ou CNPJ) e saiba o **tipo de pessoa** e o **tipo de cadastro**.
- Reúna os dados obrigatórios: nome, endereço, telefone, e-mail e credencial.
- Confirme que o seu perfil (Master ou Comum) permite criar o cliente.

## Fluxos principais

1. **Criar cliente** — clique em **"+ Novo Cliente"**, preencha o pré-cadastro e clique em **Avançar**; preencha os dados obrigatórios e clique em **Salvar** (ou **Salvar e Continuar**).
2. **Enviar para aprovação** — clique em **"Enviar Cliente"** e confirme no popup (**SIM**). O cliente vai para a fila de aprovação conforme o tipo de pessoa.
3. **Acompanhar** — o cliente fica com o status **"Em Análise pela Área de Cadastro/Crédito"** até a decisão da alçada.

<Callout type="cuidado" title="Salvar antes de enviar">

## O que a tela não faz

- Não aprova o cliente — a decisão acontece na Fila de Aprovações de Cadastro.
- Não gera o código SAP diretamente — ele é criado quando o cliente é aprovado.
- Não envia o cliente antes de salvar — o botão "Enviar Cliente" só habilita após o salvamento.
