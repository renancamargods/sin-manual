## Visão geral

O módulo **Inventários** organiza a contagem de estoque, permitindo abrir um inventário, registrar contagens e acompanhar quais inventários estão disponíveis para conferência.

## Quando usar este módulo

- Abrir um novo inventário.
- Registrar a contagem de itens.
- Consultar inventários disponíveis para contagem.

## Como acessar

Menu lateral → Módulos → Inventários

<Callout type="cuidado" title="Impacto no estoque">
As contagens registradas aqui podem gerar ajustes no saldo de estoque dos produtos.
</Callout>
