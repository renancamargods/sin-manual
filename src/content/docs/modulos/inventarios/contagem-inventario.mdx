## Visão geral

A tela **Contagem Inventário** reúne as **contagens realizadas** nos inventários de estoque. A partir dela é possível localizar um inventário e **abri-lo para contagem**, além de consultar os detalhes e o histórico de cada registro.

## Quando usar esta tela

- Localizar um inventário para registrar a contagem.
- Consultar as contagens já realizadas.
- Acompanhar o status de contagem de cada inventário.

## Como acessar

Inventários → Contagem Inventário

## Antes de começar

- Saiba o **inventário** (ID ou descrição) que será contado.
- Confira o **Centro** e o **tipo** de inventário.

## Fluxos principais

1. **Pesquisar** — informe os filtros desejados e clique em **"Pesquisar"**.
2. **Abrir para contagem** — use o ícone **Abrir Inventário** da linha para registrar a contagem.
3. **Consultar detalhes** — use o ícone de **Detalhes** para ver as informações.
4. **Consultar histórico** — use o ícone **Logs de Alteração**.

## Relação com outros processos

- **Inventário** — os inventários contados aqui são criados na tela Inventário.
- **Inventários Disponíveis** — apresenta, em cartões, os inventários abertos para iniciar a contagem.

## O que a tela não faz

- Não cria o inventário — a criação é feita na tela Inventário.
