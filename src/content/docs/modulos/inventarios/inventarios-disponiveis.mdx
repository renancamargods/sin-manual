## Visão geral

A tela **Inventários Disponíveis** apresenta, em **cartões**, os inventários que estão **abertos para contagem**. É o ponto de entrada para o responsável **escolher um inventário e iniciar a contagem**. Cada cartão mostra os dados básicos do inventário e traz os atalhos de ação.

## Quando usar esta tela

- Ver quais inventários estão abertos para contagem.
- Iniciar a contagem de um inventário.
- Consultar os detalhes ou emitir o relatório de um inventário disponível.

## Como acessar

Inventários → Inventários Disponíveis

<Callout type="atencao" title="Pode pedir autenticação de novo">
Mesmo já logado, ao abrir esta tela o sistema pode exigir uma **autorização adicional** e redirecionar para a tela de login com a mensagem "Entre com as credenciais necessárias para a página que você está tentando acessar". Se isso acontecer, informe as credenciais para prosseguir. É o comportamento esperado desta tela — não é erro.
</Callout>

## Antes de começar

- Saiba qual **inventário** (Lounge e data) você vai contar.

- **Inventário** — os inventários exibidos aqui são criados na tela Inventário.

## O que a tela não faz

- Não cria o inventário — a criação é feita na tela Inventário.
