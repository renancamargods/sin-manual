## Visão geral

A tela **Configuração de Integração SAP** reúne o cadastro dos **ambientes de integração com o SAP**. Cada ambiente define os endereços e as credenciais de conexão — **URL Base**, **URL de Token**, **SAP Client** e **Client Id** — usados para o sistema se comunicar com o SAP.

<Callout type="atencao" title="Dados técnicos e sensíveis">
Esta tela guarda dados técnicos de conexão com o SAP. As credenciais devem ser tratadas com segurança e configuradas por quem administra a integração.
</Callout>

## Quando usar esta tela

- Cadastrar um novo ambiente de integração com o SAP.
- Consultar os ambientes já cadastrados.
- Ajustar as URLs, o SAP Client ou o Client Id de um ambiente.

## Como acessar

Integrador → Configuração de Integração SAP

## Relação com outros processos

- **Fluxos de Integração** e **Monitoramento de Integrações SAP** — usam o ambiente configurado aqui para se conectar ao SAP.

## O que a tela não faz

- Não executa a integração — apenas configura os ambientes usados por ela.
