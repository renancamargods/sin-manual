## Visão geral

O módulo **Integrador** concentra o acompanhamento das integrações entre o S.I.N Implant System e outras plataformas usadas pela empresa.

## Quando usar este módulo

- Acompanhar o status de integrações ativas.
- Consultar informações trocadas com outros sistemas.

## Como acessar

Menu lateral → Módulos → Integrador

<Callout type="info" title="Uso técnico">
Este módulo é normalmente utilizado por times responsáveis por configuração e integração de sistemas.
</Callout>
