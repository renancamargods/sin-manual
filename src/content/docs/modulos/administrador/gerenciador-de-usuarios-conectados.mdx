## Visão geral

A tela **Gerenciador de Usuários Conectados** mostra, em tempo real, os usuários atualmente conectados ao sistema. Apresenta o **Total de Usuários Ativos** e uma lista com **Nome**, **E-Mail** e o horário de **Autenticado em**.

<Callout type="info" title="Tela de monitoramento">
Esta é uma tela apenas de consulta (monitoramento em tempo real). Não há cadastro nem edição — a lista se atualiza conforme os usuários entram e saem do sistema.
</Callout>

## Quando usar esta tela

- Verificar quantos e quais usuários estão conectados no momento.
- Consultar o horário de autenticação de cada usuário conectado.

## Como acessar

Administrador → Gerenciador de Usuários Conectados

## Fluxos principais

1. **Consultar** — abra a tela e veja o **Total de Usuários Ativos** e a lista de conectados.
2. **Acompanhar** — a lista se atualiza em tempo real conforme os usuários entram e saem.

## O que a tela não faz

- Não encerra sessões nem desconecta usuários — apenas exibe quem está conectado.
- Não cadastra nem edita usuários (isso é feito no módulo Autenticador).
