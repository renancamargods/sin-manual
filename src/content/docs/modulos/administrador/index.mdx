## Visão geral

O módulo **Administrator** reúne as configurações administrativas gerais do S.I.N Implant System. É voltado principalmente para quem cuida da configuração e manutenção do ambiente.

## Quando usar este módulo

- Ajustar configurações gerais que afetam todo o sistema.
- Acompanhar parâmetros administrativos do ambiente.

## Como acessar

Menu lateral → Módulos → Administrator

<Callout type="info" title="Acesso restrito">
As telas deste módulo costumam ser usadas apenas por administradores do sistema.
</Callout>
