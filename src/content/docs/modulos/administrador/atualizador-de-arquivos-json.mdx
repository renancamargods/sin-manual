## Visão geral

A tela **Atualizador de Arquivos Json** é um **Editor JSON** dos arquivos de configuração (**AppSettings**) dos serviços do sistema. Você seleciona o arquivo desejado por grupo de serviço e edita o seu conteúdo JSON.

<Callout type="cuidado" title="Tela técnica">
Esta é uma tela técnica. A edição incorreta dos arquivos de configuração pode afetar o funcionamento dos serviços do sistema. Faça alterações apenas com conhecimento do conteúdo e, preferencialmente, com apoio da equipe técnica.
</Callout>

## Quando usar esta tela

- Consultar o conteúdo de um arquivo de configuração JSON.
- Ajustar parâmetros de configuração de um serviço.

## Como acessar

Administrador → Atualizador de Arquivos Json

## Antes de começar

- Saiba **qual arquivo** (grupo de serviço) precisa editar.
- Conheça o **conteúdo** e o efeito da alteração.

## Fluxos principais

1. **Selecionar** — no campo "Selecione o arquivo json para edição", escolha o grupo de serviço desejado.
2. **Consultar / editar** — o conteúdo do arquivo é carregado no editor para consulta ou edição.
3. **Salvar** — grave as alterações (confirme que o JSON está válido).

## O que a tela não faz

- Não reinicia serviços — apenas edita os arquivos de configuração.
