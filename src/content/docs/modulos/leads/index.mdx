## Visão geral

O módulo **Leads** apoia a prospecção comercial, reunindo indicações recebidas e o acompanhamento das oportunidades até a conversão em cliente.

## Quando usar este módulo

- Registrar uma nova indicação de lead.
- Acompanhar leads pelo quadro Kanban.
- Consultar a etapa do pipeline de venda de uma oportunidade.

## Como acessar

Menu lateral → Módulos → Leads

<Callout type="info" title="Fluxo comercial">
Leads convertidos costumam originar um novo cadastro no módulo Clientes.
</Callout>
