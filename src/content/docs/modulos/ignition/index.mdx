## Visão geral

O módulo **Ignition** reúne painéis com indicadores consolidados para acompanhamento operacional do dia a dia.

## Quando usar este módulo

- Acompanhar indicadores consolidados de outras áreas do sistema.
- Monitorar o andamento de processos em tempo real.

## Como acessar

Menu lateral → Módulos → Ignition

<Callout type="info" title="Conteúdo consolidado">
Os indicadores exibidos aqui refletem informações cadastradas em outros módulos do sistema.
</Callout>
