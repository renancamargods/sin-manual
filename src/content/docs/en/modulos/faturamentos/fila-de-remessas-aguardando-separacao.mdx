## Overview

The **Shipments Awaiting Picking Queue** screen shows, as a **queue**, the shipments that still **await picking**. It is a dispatch **tracking** screen: from it, the team filters the shipments, sees the pending quantity and can **generate the picking sheets** for the filtered orders and access the **Label Queue**.

## When to use this screen

- Track which shipments still await picking.
- Filter the shipments by order, shipment, priority or order type.
- Prioritize what must be picked (priority "Urgent", etc.).
- Generate the picking sheets for the filtered orders.
- Move on to the Label Queue.

## How to access

Invoicing → Shipments Awaiting Picking Queue

## Before you start

- Know which orders or shipments you want to track (order number, shipment, customer, etc.).
- Confirm that your profile allows generating the picking sheets.

## What the screen does not do

- It does not invoice orders or create shipments — it only tracks those awaiting picking.
- It does not change the order or shipment data.
