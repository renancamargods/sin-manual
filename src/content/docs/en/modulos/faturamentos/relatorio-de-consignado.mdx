## Overview

The **Consignment Report** shows the **position of the consignment items**: by customer, product, lot and serial, with the **invoices** of each consignment stage (dispatch, return, sale, etc.) and the **balance** of each item. The report can be generated in the **Summary** or **Full** versions.

It is a **query** screen: it generates the report from the filters, without changing data.

## When to use this screen

- Query the position of a customer's consignment items.
- See the consignment balance by product, lot and serial.
- Track the invoices of the consignment stages.
- Generate the summary or full report for analysis.

## How to access

Invoicing → Consignment Report

## Before you start

- Know the customer, Lounge, invoice or period you want to query.
- Choose whether you need the "Summary" or "Full" report.
- Confirm that your profile has access to the screen.

### Report columns

The report gathers **identification** columns and, for each consignment **stage/invoice type**, a block with the invoice, the date, the value and the quantity, ending in the **Balance**.

## What the screen does not do

- It does not invoice or close the consignment — it only shows its position.
- It does not change invoices, orders or balances.
