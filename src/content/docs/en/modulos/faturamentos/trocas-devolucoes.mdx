## Overview

The **Exchanges/Returns** screen drives, end to end, the process of **product exchange and return** for a customer. Each operation starts from a **triage** and receives a **Protocol No.**; from it, the products that come back are **scanned**, the credit or debit amounts are calculated and, when applicable, the **return** and **exchange** orders are generated.

The whole progress is tracked by the **TDC Order Status** (e.g., "Triage Started", "Return Order Created", "Exchange Order Created"), and each change is recorded in the operation history.

## When to use this screen

- Start a new exchange/return triage for a customer.
- Scan and check the products the customer is returning.
- Register the exchange items and generate the return and exchange orders.
- Track the status and history of an exchange/return protocol.
- Cancel a protocol when needed.

## How to access

Invoicing → Exchanges/Returns

## Before you start

- Have the **customer** responsible for the return and the operation **center**.
- Gather the products coming back, with **DataMatrix**, lot, serial and the reference invoice.
- If any, have the related **FreshDesk ticket number**.
- Confirm that your profile allows starting a triage and generating return/exchange.

## Row icon windows

### Change log

Shows the **full history** of each operation change, with date, time and user. Each record brings the operation and item data (e.g., "TDC Order Status", "Credit or Debit amount generated", "Center", "Price List" and the returned items with lot, serial, invoice and DataMatrix).

### Details

**Read-only** window with the main operation data: Protocol No., customer, center, status, amounts and items. It does not allow changing anything.

## Main flows

1. **Start triage** — click **"+ New Triage"**, inform the "Customer Responsible for the Return" and the "Return Center".
2. **Inform the returned items** — in "Return Items", use **"Scanning"**, **"Copy and Paste"** or **"Invoice"** to inform the products coming back.
3. **Generate the return** — check the items and amounts and click **"Generate Return"**.
4. **Build the exchange** — in "Exchange Items", add the new products ("+ New Exchange Item", "+ Quick Entry Exchange Item" or "Import Items from Excel") and check the stock.
5. **Generate the exchange** — click **"Generate Exchange"** to create the outbound order for the exchange items.
6. **Track the status** — check the "Additional Information" tab and the operation "TDC Order Status".
7. **Save** — click **"Save"** to keep the progress.

<Callout type="cuidado" title="Generating creates orders">
"Generate Return" and "Generate Exchange" create orders from the operation. Review the items, the amounts and the return authorization before generating.

## What this screen does not do

- Does not invoice the orders — it only generates the return and exchange orders.
- Does not register the products or the customers — they come from their own registrations.
- Does not change already issued invoices — it uses the reference invoices for the return.
