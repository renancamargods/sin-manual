## Overview

The **DataMatrix Analysis** screen is a tool to **check** the products' **DataMatrix** codes. It lets you inform one or several items — by **scanning** (reading), by **copy and paste** of the codes or from an **invoice** — and see the data each DataMatrix carries (such as product, lot and serial), building a list that can be **exported to Excel**.

It is a **query** screen: it does not create, invoice or change orders or shipments. It is used to analyze and validate the read codes.

## When to use this screen

- Check whether a DataMatrix is legible and intact.
- Analyze the data a code carries (product, lot, serial).
- Verify several items at once, by scanning or pasting the codes.
- Pull the items of an invoice for checking.
- Export the checked list to Excel.

## How to access

Invoicing → DataMatrix Analysis

## Before you start

- Have the products with a legible **DataMatrix** to scan, or the codes to paste.
- For the query by invoice, have the **company** and the reference **invoice**.
- Confirm that your profile has access to the screen.

## What the screen does not do

- It does not invoice and does not generate orders or shipments.
- It does not change invoices or product registrations.
- It does not move stock — it only checks the informed codes.
