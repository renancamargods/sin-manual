## Overview

The **Label Generation Queue** screen gathers the **invoiced shipments** available for **generating and printing** the dispatch **labels**. It is a **queue** screen: the team filters the shipments, tracks what already had a label generated/printed and moves on to the loading list.

  ]}
/>

## When to use this screen

- See which invoiced shipments await label generation.
- Track which shipments already had a label generated or printed.
- Filter the shipments by carrier and by volume.
- Move on to the Loading List Queue.

## How to access

Invoicing → Label Generation Queue

## Before you start

- Have the shipments already **invoiced** (only they appear in the queue).
- Know the shipment, order or carrier you want to track.
- Confirm that your profile allows generating and printing the labels.

## What the screen does not do

- It does not invoice orders or create shipments — it only handles the labels of the already invoiced shipments.
- It does not change the order or shipment data.
