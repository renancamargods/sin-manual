## Overview

The **Loading List Queue** screen organizes the **loading list** stage (the load list per carrier) of dispatch. It has two parts: the **shipments awaiting the loading list** — grouped by Lounge and carrier, from which the loading list is **created** — and the **loading lists already created**, with tracking of their conference and status.

## When to use this screen

- See which shipments await the loading list, by carrier.
- Select shipments and create the loading list for dispatch.
- Track the loading lists already created and their conference.
- Query the status of a loading list.

## How to access

Invoicing → Loading List Queue

## Before you start

- Have the shipments already picked and ready for the loading list.
- Know the carrier and the Lounge of the shipments.
- Confirm that your profile allows creating loading lists.

## Main flows

1. **Select shipments** — in the "Shipments awaiting loading list" tab, filter and check the carrier's shipments.
2. **Create the loading list** — click **"+ Create Loading List"** to assemble the loading list with the selected shipments.
3. **Track** — in the "Created loading lists" tab, locate the loading list and track the volumes, the conference and the status.

<Callout type="info" title="Loading list per carrier">
The shipments are grouped by carrier; the loading list is created for the selected shipments within a carrier.

## What the screen does not do

- It does not invoice orders or create shipments — it only organizes the loading list of existing shipments.
- It does not change the shipment data.
