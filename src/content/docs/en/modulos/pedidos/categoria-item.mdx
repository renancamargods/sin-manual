## Overview

The **Item Category** screen registers the categories used to classify order items, relating them to the **ERP Order** (order type in the ERP) and the **SchedType**. Each category holds **Item Category**, **ERP Order**, **Item Category Description** and **SchedType**.

<Callout type="info" title="Technical classification">
This screen relates the item category to the ERP order type codes (ERP Order and SchedType). It is used in order integration.
</Callout>

## When to use this screen

- Register a new item category.
- Look up or find a category by description or ERP order.
- Edit a category's codes.

## How to access

Orders → Item Category

## Before you start

- Have the corresponding **Item Category**, **ERP Order** and **SchedType**.

## Main flows

1. **Search** — enter **Item Category** or **ERP Order** and click **"Search"**.
2. **Register** — click **"+ New"**, enter **Item Category**, **ERP Order**, **Description** and **SchedType** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
