## Overview

The **Order Attachment** screen lets you look up and attach documents linked to orders (for example, proofs and approvals). Each attachment holds the **File**, **Keywords**, a **Description** and the **Order** it belongs to.

## When to use this screen

- Attach a document to an order.
- Look up or find an attachment by name.
- Download, edit or delete an attachment.

## How to access

Orders → Order Attachment

## Before you start

- Have the **file** to attach and the corresponding **order**.
- Define **keywords** and a **description** to make searching easier.

## Main flows

1. **Search** — enter the **"Name"** and click **"Search"**.
2. **Attach** — click **"+ New"**, choose the **File**, enter **Keywords** and **Description**, select the **Order** and click **"Save"**.
3. **Download** — use the download icon on the attachment row.
4. **Edit / Delete** — use the **Edit** and **Delete** icons on the row.

- It does not change the order — it only manages the documents attached to it.
