## Overview

The **Item Type** screen registers the types used to classify order items. Each record holds the **Item Type** and the **Item Type Code**.

  cards={[

  ]}
/>

## When to use this screen

- Register a new item type.
- Look up or find a type by its code.
- Edit or delete a type.

## How to access

Orders → Item Type

## Before you start

- Have the **Item Type** and the **Item Type Code**.

## Main flows

1. **Search** — enter the **"Item Type Code"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Item Type** and the **Item Type Code** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
