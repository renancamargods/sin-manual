## Overview

The **Quote** screen lets you register and track sales quotes. Each quote has a **Header** (Lounge, Price List, Observation and % Financial Discount) and a list of **Sale Items** (product, type, quantity, prices and discount). The quote evolves through a **Status** (for example, "In Negotiation") and precedes the creation of the order.

## When to use this screen

- Register a new quote.
- Add sale items to the quote (manually, by quick entry or importing from Excel).
- Track the quote status.

## How to access

Orders → Quote

## Before you start

- Select the **Lounge** (needed to check the stock balance).
- Choose the **Price List** and set the **% Financial Discount**, if any.

## Main flows

1. **Search** — enter the **Quote Number** or the **Issuing User** and click **"Search"**.
2. **Register** — click **"+ New"**, select the **Lounge** and the **Price List**, adjust the **% Financial Discount** and add the items.
3. **Add items** — use **"+ Add Quote Item"**, **"Add Item - Quick Entry"** or **"Import Items from Excel"**.
4. **Track** — check the **Quote Status** and the **Net Total Value**.

- It does not issue the invoice — the quote precedes the order and invoicing.
