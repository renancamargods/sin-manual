## Overview

The **Orders** module concentrates the entire commercial cycle of a sales order: quote, order creation, items, approval, freight, invoicing and invoice.

## When to use this module

- Create and track a sales order.
- Build a quote for the customer.
- Look up issued invoices.
- Configure price lists, currencies and freight rules.

## How to access

Side menu → Modules → Orders

<Callout type="cuidado" title="A multi-step process">
An order may go through approval, freight calculation and invoicing before it is completed. Review each stage before confirming.
</Callout>
