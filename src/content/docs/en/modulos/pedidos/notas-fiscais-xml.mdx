## Overview

The **Invoice XML** screen lets you look up and **download the XML files** of the invoices. You filter by several criteria (customer, period, CFOP, operation nature, carrier, value) and use the **"Generate zip file and download"** action to download the selected XMLs.

<Callout type="info" title="Lookup and download screen">
This screen is used to find invoices and download their XMLs in a zip file. It does not issue or change invoices.
</Callout>

## When to use this screen

- Download the XMLs of invoices from a period or customer.
- Filter invoices by CFOP, operation nature, carrier or value.

## How to access

Orders → Invoice XML

## Before you start

- Define the filters (customer, period, CFOP, operation nature, carrier, value).

## Main flows

1. **Search** — enter the filters and click **"Search"**.
2. **Select** — check the desired invoices (or use **"Select all"**).
3. **Download** — click **"Generate zip file and download"** to download the XMLs.
