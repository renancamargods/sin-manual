## Overview

The **Smart Operation** screen registers the rules that relate the **Order Type** (for example, Bonus, Campaign, Sale, Return) to the corresponding **ERP Order**, defining parameters such as foreign trade availability, **Related TDC Operation** (Return, Exchange, Consignment), integration and the **Origin Order Types**. It is through these rules that the system automates the behavior when creating orders.

## When to use this screen

- Register a new smart operation for an order type.
- Define the ERP order and the rules (foreign trade, TDC, integration) of an order type.
- Look up, edit or delete operations.

## How to access

Orders → Smart Operation

## Before you start

- Know the **Order Type** and the corresponding **ERP Order**.
- Define the rules (foreign trade, TDC operation, integration) and the origin order types.

## Main flows

1. **Search** — enter the **Observation** and/or the **Status** and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Observation**, the **ERP Order**, the **Order Type** and the rules (foreign trade, TDC, integration, ZP/P, origin order types) and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
