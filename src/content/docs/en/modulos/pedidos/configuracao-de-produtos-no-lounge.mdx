## Overview

The **Product Configuration in the Lounge** screen defines which products (by **SKU Code**) are available and searchable in each **Lounge**, with a **Search Order** and the scope by **country, state and city**. It is through this screen that the system knows which products to offer in each unit and location.

## When to use this screen

- Configure a product's availability in a Lounge.
- Define the search order and the geographic scope of a product.
- Look up, edit or delete configurations.

## How to access

Orders → Product Configuration in the Lounge

## Before you start

- Have the product's **SKU Code** and the **Lounge**.
- Define the **search order** and the scope (country/state/city), if applicable.

## Main flows

1. **Search** — enter **Family**, **Group** or the other filters and click **"Search"**.
2. **Register** — click **"+ New"**, select the **SKU Code**, enter the **Search Order**, the **Country** and the **Lounge Name**, set the **Status** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
