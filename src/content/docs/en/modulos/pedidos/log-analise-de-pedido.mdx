## Overview

The **Order Review Log** screen lets you look up the history of the automatic reviews applied to orders. For each execution, the log shows the **Order Number**, the **Customer Code**, the **Applied Rule**, the **Reason** and the **Result**, with the **Execution Date**.

<Callout type="info" title="Lookup screen">
This is a lookup screen (log). It records what the system did in the order reviews, serving for traceability.
</Callout>

## When to use this screen

- Look up which rules were applied in an order's review.
- Check the reason and the result of a review.

## How to access

Orders → Order Review Log

## Before you start

- Have, if needed, the **Order Number**, the **Customer Code** or the **Applied Rule** to filter.

## Main flows

1. **Search** — enter the filters (Order Number, Customer Code, Applied Rule) and click **"Search"**.
2. **Analyze** — check the applied rule, the reason and the result of each execution.
