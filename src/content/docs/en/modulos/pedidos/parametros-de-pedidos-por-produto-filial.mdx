## Overview

The **Order Parameters by Product/Branch** screen defines, by **product**, **center/branch** and **location** (country, state, city), **which parameters** apply when assembling the order. Each record has a **Search Order**, which sets the priority when more than one record could apply.

The segmentation is done through **collections**: one record can apply to several **countries**, **states**, **cities**, **types**, **groups**, **product families** and **products**.

## When to use this screen

- Define order parameters specific to a center/branch.
- Restrict parameters to certain products or locations.
- Adjust the priority (search order) between overlapping records.

## How to access

Orders → Order Parameters by Product/Branch

## Before you start

- Have the target **Center/Branch**.
- Define the **countries** (and, if applicable, states/cities) and the **product types/groups/families** the record covers.

## Validation rules

Geography is **hierarchical** — you cannot set a level without the level above it:

  headers={['Field', 'Rule']}

## Main flows

1. **Query** — enter the filters and search the records.
2. **Register** — click **"+ New"**, enter the **Center**, the **Search Order**, the **Status** and the links (**countries**, **states/cities** when applicable and **product types**) and **save**.
3. **Edit / Delete** — use the row actions to change or remove a record.

## What this screen does not do

- It does not create products or centers/branches — it only links those already registered to segment the parameters.
