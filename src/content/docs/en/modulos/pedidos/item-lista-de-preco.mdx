## Overview

The **Price List Item** screen registers the items that make up a price list, relating a **Product** to a **Price** and a **validity**. It is through these items that the list defines how much each product costs.

  cards={[

/>

## When to use this screen

- Register a product's price in a list.
- Look up items by product, list or visibility.
- Edit or delete a price item.

## How to access

Orders → Price List Item

## Before you start

- Have the **Product**, the **Price** and the **validity**.
- Register the **price list** first, if needed.

## Main flows

1. **Search** — enter **Product**, **List** or the other filters and click **"Search"**.
2. **Register** — click **"+ New"**, select the **Product**, enter the **Price** and the **validity** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

## What this screen does not do

- It does not create the list — only the items (product and price) within it.
