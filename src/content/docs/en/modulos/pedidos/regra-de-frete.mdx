## Overview

The **Freight Rule** screen defines the rules that determine the **Freight Amount** applied to the order. Each rule combines criteria such as **Priority**, **value range** (Value from / Value to), **region** (ZIP range, State, City, Lounge), **Customer**, **Carrier** and the **Domestic or International** scope.

## When to use this screen

- Register a new freight rule.
- Define the freight amount by priority, value range and region.
- Look up, edit or delete rules.

## How to access

Orders → Freight Rule

## Before you start

- Define the criteria: **priority**, **value range**, **region** (ZIP/state/city/Lounge) and **carrier**.
- Have the **Freight Amount** to apply.

## Main flows

1. **Search** — enter the **"Description"** and click **"Search"**.
2. **Register** — click **"+ New"**, define the criteria (priority, value range, region, customer, carrier), enter the **Freight Amount** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
