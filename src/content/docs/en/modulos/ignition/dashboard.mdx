## Overview

The **Dashboard** (Ignition) screen is the **monitoring panel** of the system automatic tasks and services. It tracks, in **real time**, the running and executed tasks, with the detailed record (log) and the history, plus operation controls.

<QuickCards
  cards={[

  ]}
/>

## When to use this screen

- Track the automatic tasks and services in real time.
- Look up the detailed log and the task history.
- Check the task waiting queue.

## How to access

Ignition → Dashboard

## What this screen does not do

- Does not register tasks or services — it only monitors and operates the existing ones.
- Does not change the task rules — they are defined in the system configuration.
