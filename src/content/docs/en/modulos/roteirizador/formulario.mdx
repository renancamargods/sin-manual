## Overview

The **Form** screen gathers the registration of the **forms** used in the field. Each form has a **description** and gathers, in a tab, the **fields** that make it up (the "Form Field" tab). The forms are filled in during services.

  cards={[
    { label: 'Purpose', title: 'Form registration', text: 'Defines the forms used in field services.' },

    { label: 'Caution', title: 'Form fields', text: 'Build the fields that make up the form in the corresponding tab.' },
  ]}
/>

## When to use this screen

- Register a new form.
- Check the forms already registered.
- Build or adjust the fields of a form.

## How to access

Field Routing → Form
