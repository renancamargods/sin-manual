## Overview

The **Form Field** screen gathers the registration of the **fields** that make up the field forms. Each field has a **description**, a **code**, a **type** and the **mandatory** indication.

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Form fields', text: 'Defines the fields used in the field forms.' },
    { label: 'Use', title: 'Form structure', text: 'The fields make up the forms filled in the visit.' },
    { label: 'Caution', title: 'Type and mandatory', text: 'Check the field type and whether it is mandatory.' },
  ]}
/>

## When to use this screen

- Register a new form field.
- Check the fields already registered.
- Adjust the type or the mandatory flag of a field.

## How to access

Field Routing → Form Field
