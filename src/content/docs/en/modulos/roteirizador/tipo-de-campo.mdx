## Overview

The **Field Type** screen gathers the registration of the **field types** available for the Field Routing forms. Each type has a **description** and is used when defining the fields of a form.

  cards={[

/>

## When to use this screen

- Register a new field type.
- Check the types already registered.

## How to access

Field Routing → Field Type
