## Overview

The **Absence** screen gathers the registration of the **absences** that affect the Field Routing schedule. Each absence has a **reason**, a **type** and a **period** (start and end date), and it impacts the availability in the service schedule.

  cards={[

    { label: 'Caution', title: 'Correct period', text: 'Check the start and end dates of the absence.' },
  ]}
/>

## When to use this screen

- Register an absence that affects the schedule.
- Check the absences already registered.
- Adjust the reason, the type or the period of an absence.

## How to access

Field Routing → Absence
