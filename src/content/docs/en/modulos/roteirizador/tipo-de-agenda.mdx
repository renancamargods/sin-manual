## Overview

The **Schedule Type** screen gathers the registration of the **schedule types** used to **classify the services** of Field Routing. Each type has a **description** and the indication of whether it is a **visit**.

  cards={[
    { label: 'Purpose', title: 'Schedule types', text: 'Classifies the services by type.' },
    { label: 'Use', title: 'Schedule organization', text: 'The types organize the services in the schedule.' },
    { label: 'Caution', title: 'Visit?', text: 'Indicate whether the type corresponds to a visit.' },
  ]}
/>

## When to use this screen

- Register a new schedule type.
- Check the types already registered.

## How to access

Field Routing → Schedule Type
