## Overview

The **Schedule Form** screen makes the **association between forms and schedules** (service types) of Field Routing. It defines **which form** is used in each schedule/service, linking the Form registration to the Schedule.

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Form x schedule', text: 'Associates each form with the service schedule.' },
    { label: 'Use', title: 'Standardized collection', text: 'Ensures the right form is used in each service.' },
    { label: 'Caution', title: 'Correct link', text: 'Check the association between the form and the schedule.' },
  ]}
/>

## When to use this screen

- Associate a form with a schedule/service type.
- Check the associations already made.

## How to access

Field Routing → Schedule Form

<Callout type="atencao" title="Access via the related screen">
In the homologation environment, direct access by URL to this screen may return "Page not found". The association between form and schedule is usually managed from the related screens (Form and Schedule). If direct access fails, use the menu path or the Form screen.
</Callout>

## What this screen does not do

- It does not register the form or the schedule — it only associates one with the other.
