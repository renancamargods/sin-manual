## Overview

The **SAP Integrations Monitoring** screen lets you **query and track the integrations** between the system (CRM) and SAP. Each record shows the integrated **entity** (e.g., Customer), the **status** of the integration, the **CRM ID** and the **SAP ID**, plus the creation and update dates. It is a **query** screen, useful to identify pending integrations or ones that need manual action.

## When to use this screen

- Track the status of the SAP integrations.
- Locate records with the status "Awaiting Manual Action" or pending ones.
- Check the ID of a record in the CRM and in SAP.

## How to access

Integrator → SAP Integrations Monitoring

## Relationship with other processes

- **SAP Integration Configuration** — defines the connection environment used.
- **Integration Flows** — run the integrations that appear here.

## What this screen does not do

- It does not register or change records — it is a query screen.
- It does not configure the integration — that is done in SAP Integration Configuration and Integration Flows.
