## Overview

The **Stage Type** screen gathers the registration of the **stage types** used in **integration flows**. Each type defines how the stage is executed — the **executor type**, the **base endpoint** and the **payload mapper** — and is reused when building the stages of a flow.

  ]}
/>

## When to use this screen

- Register a new stage type.
- Check the types already registered.
- Adjust the executor, the endpoint or the mapper of a stage type.

## How to access

Integrator → Stage Type
