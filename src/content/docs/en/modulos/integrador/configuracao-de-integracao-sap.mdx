## Overview

The **SAP Integration Configuration** screen gathers the registration of the **SAP integration environments**. Each environment defines the connection addresses and credentials — **Base URL**, **Token URL**, **SAP Client** and **Client Id** — used for the system to communicate with SAP.

<Callout type="atencao" title="Technical and sensitive data">
This screen stores technical SAP connection data. The credentials must be handled securely and configured by whoever administers the integration.
</Callout>

## When to use this screen

- Register a new SAP integration environment.
- Check the environments already registered.
- Adjust the URLs, the SAP Client or the Client Id of an environment.

## How to access

Integrator → SAP Integration Configuration

## Relationship with other processes

- **Integration Flows** and **SAP Integrations Monitoring** — use the environment configured here to connect to SAP.

## What this screen does not do

- It does not run the integration — it only configures the environments used by it.
