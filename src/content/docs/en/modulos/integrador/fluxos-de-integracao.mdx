## Overview

The **Integration Flows** screen gathers the registration of the **integration flows** with SAP and their **stages**. Each flow has a name, a description and a set of stages (e.g., "BillingDocument", "BusinessPartner", "OutboundDelivery", "SalesOrder"), which define the sequence of steps of the integration.

## When to use this screen

- Register a new integration flow.
- Check the flows already registered and the number of stages.
- Adjust the name, the description or the stages of a flow.

## How to access

Integrator → Integration Flows

## Relationship with other processes

- **Stage Type** — the flow stages use the registered stage types.
- **SAP Integration Configuration** — defines the connection environment used by the flows.
- **SAP Integrations Monitoring** — tracks the execution of the integrations.
