## Overview

The **Integrator** module concentrates the tracking of integrations between the S.I.N Implant System and other platforms used by the company.

## When to use this module

- Track the status of active integrations.
- Look up information exchanged with other systems.

## How to access

Side menu → Modules → Integrator

<Callout type="info" title="Technical use">
This module is normally used by teams responsible for system configuration and integration.
</Callout>
