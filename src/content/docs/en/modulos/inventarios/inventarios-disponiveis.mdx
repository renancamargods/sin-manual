## Overview

The **Available Inventories** screen shows the inventories that are **available for counting**, as cards. Each card shows the **inventory name**, the **Lounge**, the **Inventory Date**, the **Inventory Type** and the **System Status**, with the actions to **start the count** or consult the inventory. It is the day-to-day entry point for whoever will count.

## When to use this screen

- See the inventories available for counting.
- Start the count of an inventory.
- Consult the details or issue the report of an inventory.

## How to access

Inventories → Available Inventories

## Relation to other processes

- **Inventory** — the inventories created on the [Inventory](/en/modulos/inventarios/inventario) screen are the ones shown here as available.
- **Inventory Count** — the count started here is recorded and tracked in the counting process.

## What the screen does not do

- It does not create the inventory — the registration is done on the **Inventory** screen.
- It does not perform the count itself — the count happens after "Start Count", via scanning.
