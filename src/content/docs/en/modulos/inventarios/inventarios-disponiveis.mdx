## Overview

The **Available Inventories** screen presents, as **cards**, the inventories that are **open for counting**. It is the entry point for the responsible person to **choose an inventory and start the count**. Each card shows the inventory's basic data and provides the action shortcuts.

  cards={[

  ]}
/>

## When to use this screen

- See which inventories are open for counting.
- Start the count of an inventory.
- View the details or issue the report of an available inventory.

## How to access

Inventories → Available Inventories

<Callout type="atencao" title="It may ask you to sign in again">
Even when already logged in, opening this screen may require an **additional authorization** and redirect to the login screen with the message "Enter the credentials required for the page you are trying to access". If that happens, enter the credentials to continue. This is the expected behavior of this screen — it is not an error.
</Callout>

## Before you start

- Know which **inventory** (Lounge and date) you are going to count.

## Relationship with other processes

- **Inventory** — the inventories shown here are created on the Inventory screen.
- **Inventory Count** — concentrates the recording of the counts performed.

## What this screen does not do

- It does not create the inventory — creation is done on the Inventory screen.
