## Overview

The **Inventory Count** screen gathers the **counts performed** on stock inventories. From it you can locate an inventory and **open it for counting**, as well as view the details and history of each record.

## When to use this screen

- Locate an inventory to record the count.
- Check the counts already performed.
- Track the counting status of each inventory.

## How to access

Inventories → Inventory Count

## Before you start

- Know the **inventory** (ID or description) to be counted.
- Check the **Center** and the **type** of inventory.

## Main flows

1. **Search** — enter the desired filters and click **"Search"**.
2. **Open for counting** — use the **Open Inventory** icon on the row to record the count.
3. **View details** — use the **Details** icon to see the information.
4. **View history** — use the **Change Logs** icon.

## Relationship with other processes

- **Inventory** — the inventories counted here are created on the Inventory screen.
- **Available Inventories** — presents, as cards, the inventories open to start the count.

## What this screen does not do

- It does not create the inventory — creation is done on the Inventory screen.
