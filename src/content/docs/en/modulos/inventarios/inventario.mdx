## Overview

The **Inventory** screen gathers the registration and tracking of stock inventories. Each inventory represents a **count of a Lounge** on a date, with a **type** (General or Cyclic) and a **status** that advances as the count is performed (for example: "Inventory Created", "First Count", "Second Count" and "Count Finished").

## When to use this screen

- Register a new inventory for a Lounge.
- Check the inventories already created and the status of each one.
- Run the count of an inventory.
- Issue the report of an inventory.

## How to access

Inventories → Inventory

## Before you start

- Know the **Lounge** to be inventoried.
- Define the inventory **type**: "General" or "Cyclic".
- Have, when applicable, the corresponding **SAP Inventory**.

## Main flows

1. **Search** — enter the desired filters and click **"Search"**.
2. **Register** — click **"+ New"**, fill in the fields and click **"Save"**.
3. **Run count** — use the **Run Count** icon on the row to record the inventory count.
4. **Edit** — use the **Edit** icon on the row, adjust the fields and click **"Save"**.
5. **Issue report** — use the **Report** icon on the row.

## Relationship with other processes

- **Available Inventories** and **Inventory Count** — use the inventories created here as the basis for the count.

## What this screen does not do

- It does not perform the count itself — the count is done through the "Run Count" action (or the Available Inventories screen).
- It does not create the inventory in SAP — it only links the record to the SAP inventory.
