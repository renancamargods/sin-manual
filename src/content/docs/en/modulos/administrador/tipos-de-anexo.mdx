## Overview

The **Attachment Types** screen registers the attachment classifications used in the system (for example, ID Document, Articles of Association, Proof of Address). Each type is linked to an **Attachment Domain**, can be marked as **Required** and be restricted by **Person Types**.

## When to use this screen

- Register a new attachment type.
- Define whether a type is required and which person types it applies to.
- Look up, edit or delete existing types.

## How to access

Administrator → Attachment Types

## Before you start

- Know which **Attachment Domain** the type belongs to (register the domain first, if needed).
- Define whether the type is **required** and the applicable **person type**.

## Main flows

1. **Search** — enter the filters and click **"Search"**.
2. **Register** — click **"+ New"**, select the **Attachment Domain**, enter the **Description**, set **Required** and **Person Types** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

- It does not store the files — it only defines the types and their rules (required flag, person type).
