## Overview

The **Attribute** screen lets you register custom attributes that can be associated with a system **Entity** — **Customer**, **Order** or **Product**. Each attribute has a **Name**, a **Type** and a set of **Values** (on the "Values" tab), acting as a configurable additional field for that entity.

## When to use this screen

- Register a new attribute for Customer, Order or Product.
- Define the possible values of an attribute.
- Look up, edit or delete existing attributes.

## How to access

Administrator → Attribute

## Before you start

- Define the **entity** (Customer, Order or Product) that will receive the attribute.
- Have the attribute's **name** and **type**.
- List the possible **values**, if applicable.

## Main flows

1. **Search** — select the **Entity** and/or enter the **Name** and click **"Search"**.
2. **Register** — click **"+ New"**, choose the **Entity**, enter **Name** and **Type**, register the **Values** on the corresponding tab and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

## What this screen does not do

- It does not fill the attribute value on a specific record — it only defines the attribute and its possible values.
