## Overview

The **Job** screen keeps the register of system jobs. Each job holds a **Description** and an associated **Profile**. It is a simple supporting register.

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Job register', text: 'Registers jobs linked to a profile.' },
    { label: 'Use', title: 'Support', text: 'Jobs become available according to the associated profile.' },
    { label: 'Caution', title: 'Profile', text: 'Associate the correct profile with the job.' },
  ]}
/>

## When to use this screen

- Register a new job.
- Look up or find a job by description or profile.
- Edit or delete a job.

## How to access

Administrator → Job

## Before you start

- Have the job's **description**.
- Know the associated **profile**.

## Main flows

1. **Search** — enter the filters and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Description**, select the **Profile** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
