## Overview

The **Post** screen registers the publications and notices shown in the system. Each post has a **Title**, a display period (**Availability Date** and **Show Until**), a **Type** (Notification or Poll) and a **Disclosure Form** (General, Profile, Company or Mixed). The content is built in a **Visual Editor** (or via the "Code" tab).

## When to use this screen

- Register a new publication (notification or poll).
- Define the audience and the display period.
- Build the content in the visual editor.
- Look up, edit or delete publications.

## How to access

Administrator → Post

## Before you start

- Have the publication's **title** and **content**.
- Define the **type** (Notification or Poll), the **disclosure form** and the **period**.

## Main flows

1. **Search** — enter **Title**, **Type** or **Profile** and click **"Search"**.
2. **Register** — click **"+ New"**, fill in the data (title, dates, type, disclosure form), click **"Continue to the Visual Editor"** to build the content and save.
3. **Edit** — click the **Edit** icon on the row, adjust the data/content and save.
4. **Delete** — click the **Delete** icon on the row.

- It does not send external emails — the publication is shown inside the system according to the disclosure form.
