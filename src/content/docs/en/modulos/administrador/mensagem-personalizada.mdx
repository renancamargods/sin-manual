## Overview

The **Custom Message** screen lets you register and look up the standardized messages the system uses in routines such as order rejection, approval and cancellation. Each message is linked to a **Message Type** (for example, RecusaPedidoCredito or AprovacaoPedidoPadraoAdm).

When creating a message, you choose the Message Type and write the text. You can also register a **new Message Type** (with Code and Description) directly from the screen, without leaving the message registration.

## When to use this screen

- Register a new standardized message.
- Look up or filter messages by type or period.
- Edit or delete an existing message.
- Register a new Message Type.

## How to access

Administrator → Custom Message

## Before you start

- Know which **Message Type** the message belongs to.
- Have the message text ready.
- If the type does not exist yet, register it (Code and Description) via the new type button.

## Main flows

1. **Look up** — enter the filters (Message, period and Message Type) and click **"Search"**.
2. **View details** — click the **View/Detail** icon on the row.
3. **Register a message** — click **"+ New"**, select the **Message Type ID**, write the **Message** and click **"Save"**.
4. **Register a new Message Type** — in the message window, click the **"+"** next to "Message Type ID", enter **Code** and **Description** and click **"Save"** (or **"Save and Continue"**).
5. **Edit a message** — click the **Edit** icon, change the fields and click **"Save"**.
6. **Delete a message** — click the **Delete** icon on the row.
7. **Clear filters** — click **"Clear Filters"** to start the search over.

## What the screen does not do

- It does not apply the message by itself — it is used by the routines according to the type.
- It does not define the policy or rule — only the standard text that will be shown.
