## Overview

The **Destination Port** screen keeps the register of ports used as destinations in foreign trade operations. Each port holds the **Port Name**, the **Port Code** and the **country** it belongs to.

  ]}
/>

## When to use this screen

- Register a new destination port.
- Look up or find a port by its name.
- Edit a port's code or country.

## How to access

Administrator → Destination Port

## Before you start

- Have the port's **name** and **code**.
- Know which **country** it belongs to (register the country first, if needed).

## Main flows

1. **Search** — enter the **"Port Name"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter **Port Name**, **Port Code** and **Country Id** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

## What this screen does not do

- It does not calculate routes or transport costs — it only registers the destination port.
