## Overview

The **Label Printer** screen registers the printers used to generate labels in each **Lounge**. Each printer has a **Connection Type** (Network or Shared), can be set as the unit's **Default** and have an **Observation**.

## When to use this screen

- Register a new label printer.
- Set the default printer of a Lounge.
- Look up, edit or delete printers.

## How to access

Administrator → Label Printer

## Before you start

- Know the printer's **Lounge** (Center).
- Define the **Connection Type**: Network (IP address and port) or Shared (shared path).

<Callout type="info" title="Connection type">
For **Network** printers, enter the IP address and port. For **Shared** printers, enter the shared path (e.g., a network path to the ZPL printer).
</Callout>

## Main flows

1. **Search** — enter the **"Name"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Name**, choose the **Connection Type**, select the **Center**, set **Default** and **Active** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
