## Overview

The **Questionnaires** screen lets you build questionnaires with their **questions** and look up the **answers**. Each questionnaire has a **Name**, a status (Active/Inactive) and a list of questions — each with a **Description**, **Question Type** and a **Required?** flag.

## When to use this screen

- Register a new questionnaire.
- Add questions with their type and required flag.
- Look up the answers of a questionnaire.

## How to access

Administrator → Questionnaires

## Before you start

- Have the questionnaire's **name** and the list of **questions**.
- Define each question's **type** and whether it is **required**.

## Main flows

1. **Search** — enter the filters and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Name**, set the **Status**, add the questions with **"+ New Question"** (Description, Question Type, Required?) and click **"Save"**.
3. **Look up answers** — open the questionnaire and access the **"Questionnaire Answers"** tab.
4. **Edit / Delete** — use the **Edit** and **Delete** icons on the row.
