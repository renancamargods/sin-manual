## Overview

The **PIX Reconciler** screen lets you **look up** and **run** the reconciliation of payments made via PIX. It relates the **PIX Code** to the **Order** and the **Customer**, and shows the result of the document update in **SAP** (message and type).

<Callout type="info" title="Lookup and action screen">
This is a lookup and execution screen: besides listing the reconciliations, it lets you trigger the reconciliation (Run Reconciliation). It is not a common register.
</Callout>

## When to use this screen

- Look up PIX reconciliations by code, customer, order or date.
- Check the SAP update return of each payment.
- Run the PIX reconciliation.

## How to access

Administrator → PIX Reconciler

## Before you start

- Have, if needed, the **PIX Code**, the **Order**, the **Customer** or the **Date** to filter.

## Main flows

1. **Search** — enter the filters (PIX Code, Customer, Order, Date) and click **"Search"**.
2. **Run reconciliation** — use the **"Run Reconciliation"** option and click **"Search"** to trigger the process.
3. **Check the return** — analyze the "SAP Message" and "Message Type" columns to confirm the result.

## What this screen does not do

- It does not generate the PIX payment — it only reconciles existing payments with orders and SAP.
