## Overview

The **Address** screen centralizes the lookup and registration of the addresses used in the system. Each address holds the full street data (type, street, number, complement, district), the **ZIP code**, the **city**, the **state**, the **address type** (Delivery, Billing or Correspondence) and the **status**.

When registering, entering the **ZIP code** and clicking search automatically fills in the address data (street, district, city and state) when available.

## When to use this screen

- Look up addresses by ZIP code, street, type or status.
- Register a new address from the ZIP code.
- Edit or review an address's data.

## How to access

Administrator → Address

## Before you start

- Have the **ZIP code** (the search fills in the other fields when available).
- Know the **address type** (Delivery, Billing or Correspondence).

## Main flows

1. **Search** — enter the filters (Address Type, ZIP code, Street, Status) and click **"Search"**.
2. **Register** — click **"+ New"**, select the **Country**, enter the **ZIP code** and trigger the search, adjust the data if needed, set the **Address Type** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **View details / history** — use the **Details** and **History/Logs** icons on the row.
5. **Delete** — click the **Delete** icon on the row.

## What this screen does not do

- It does not validate the physical existence of the address — it only records the data entered.
- It does not define which address a customer uses in each operation — that is handled in the records that consume the address.
