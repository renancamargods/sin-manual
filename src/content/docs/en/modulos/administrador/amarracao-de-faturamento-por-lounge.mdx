## Overview

The **Lounge Invoicing Binding** screen defines, for a **region** (State, City and Street), which Lounges handle invoicing in priority order: **Primary Lounge**, **Secondary Lounge** and **Tertiary Lounge**. It is a routing rule: from the location, the system knows which unit should invoice.

## When to use this screen

- Register a new invoicing binding for a region.
- Define the primary, secondary and tertiary Lounges of a region.
- Look up, edit or delete existing bindings.

## How to access

Administrator → Lounge Invoicing Binding

## Before you start

- Have the **region** (State, City and, if applicable, Street).
- Know the **Lounges** that should handle each priority level.

## Main flows

1. **Search** — enter the **"Title"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Title**, the region (**State**, **City**, **Street**) and the **Lounges** (primary, secondary, tertiary) and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
