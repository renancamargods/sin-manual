## Overview

The **Project Mode** screen configures special system operation modes during a **period** — for example, the **Fair Mode** used at events (such as CIOSP). Each mode has a **Description**, **Start Date** and **End Date**, **Parameter**, **Observation**, the **Users** it applies to and the **Enable Fair Mode** option.

## When to use this screen

- Register a new operation mode for a period.
- Enable Fair Mode at an event.
- Look up, edit or delete configured modes.

## How to access

Administrator → Project Mode

## Before you start

- Have the **description** and the **start and end dates**.
- Know the applicable **users** and **parameter**.

## Main flows

1. **Search** — enter the **"Description"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter **Description**, **dates**, **Parameter**, **Users** and set **Enable Fair Mode** and the **Status** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
