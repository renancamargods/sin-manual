## Overview

The **Service Execution Log** screen records the executions of system services and integrations — for example, queries sent to **SAP**. For each execution, it shows the date, the type, whether it succeeded, the parameters sent and the return message.

Integration logs are **filled in automatically** as the system runs the services, at the configured recording points. The screen lets you **look up** and **edit** existing records. It is useful for tracking integrations and identifying failures (for example, a product that is not registered in the CRM).

## When to use this screen

- Look up service executions in a period.
- Filter by type (e.g., SAP) or by success (Yes/No).
- Check the return message of a failed execution.
- Edit an existing log record.

## How to access

Administrator → Service Execution Log

## Before you start

- Set the period you want to look up (Start Date and End Date).
- If you wish, enter the Type (e.g., SAP) and the Success filter.
- Confirm that you have permission to access the screen.

## Main flows

1. **Look up** — enter the period (and, if you wish, Type and Success) and click **"Search"**.
2. **View details** — click the **View/Detail** icon on the row.
3. **Edit record** — click the **Edit** icon, change the fields and click **"Save"**.
4. **Delete record** — click the **Delete** icon on the row.
5. **Clear filters** — click **"Clear Filters"** to start the search over.

## What the screen does not do

- It does not allow creating records manually — logs are generated by the configured executions.
- It does not run the service itself — it only records and looks up the executions.
- It does not fix the cause of the failure — the fix is made in the corresponding record or integration.
