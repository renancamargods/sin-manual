## Overview

The **Attachment Domain** screen registers the **domains** (origins) that group the system's attachment types. Each domain holds a **Code** and a **Description** and, on the "Attachment Types" tab, gathers the types that belong to it (for example, the "Customers" domain groups the customer attachment types).

## When to use this screen

- Register a new attachment domain.
- Look up or find a domain by code or description.
- Review the attachment types linked to the domain.

## How to access

Administrator → Attachment Domain

## Before you start

- Have the domain's **code** and **description**.

## Main flows

1. **Search** — enter **Description** or **Code** and click **"Search"**.
2. **Register** — click **"+ New"**, enter **Code** and **Description** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

## What this screen does not do

- It does not register attachment types directly — the "Attachment Types" tab only shows the linked ones.
- It does not store the attached files — it only organizes the origins.
