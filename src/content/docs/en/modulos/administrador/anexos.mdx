## Overview

The **Attachments** screen gathers, in one place, the documents attached in the system records. In it you can **search, look up and manage** the attachments by **domain** (the attachment origin, such as "Customers") and by **type** (the document classification, such as "Identification Document").

Each listed attachment brings the domain, the type, the file name, the description, the related record (e.g., the customer) and the registration date, plus the actions to **download**, view **details**, **edit** or **delete**.

<Callout type="info" title="Attachments come from other screens">
This screen **does not add** attachments: the documents are added in the origin registrations (e.g., the Customer registration). Here you **look up and manage** the existing attachments.
</Callout>

## When to use this screen

- Find an attachment by name, description, domain or type.
- Download a document attached to a record.
- Look up the details of an attachment.
- Edit or delete an existing attachment.

## How to access

Administrator → Attachments

## Before you start

- Know the attachment domain (the origin, e.g., "Customers") and, if possible, the document type.
- Have the file name or the description at hand to speed up the search.
- Confirm that your profile allows accessing and managing attachments.

## Main flows

1. **Search attachments** — enter the filters ("Attachment Name", "Description", "Attachment Domains" or "Attachment Types") and click **"Search"**.
2. **Download an attachment** — in the desired row, use the **Download** icon.
3. **Look up details** — use the **Details** icon to see the attachment information.
4. **Edit an attachment** — use the row's **Edit** icon and adjust the data.
5. **Delete an attachment** — use the row's **Delete** icon (red X).

<Callout type="cuidado" title="Deleting removes the document">
Deleting an attachment removes the document from the related record. Confirm before deleting.
</Callout>

## What this screen does not do

- Does not add attachments — the documents are added in the origin registrations (e.g., the Customer registration); this screen only looks up and manages the existing ones.
- Does not create the origin records (customer, lead, survey) — it only gathers the attachments linked to them.
- Does not define the available domains and types — they come from the system configuration.
- Does not change the related record (e.g., the customer data).
