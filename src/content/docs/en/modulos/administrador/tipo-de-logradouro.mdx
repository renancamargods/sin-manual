## Overview

The **Street Type** screen keeps the list of street types (for example, Street, Avenue, Square) used to compose addresses and streets. It is a simple register, with a single **Type** field.

## When to use this screen

- Register a new street type.
- Look up or find an existing type.
- Edit or delete a type.
- Review the addresses and streets linked to the type.

## How to access

Administrator → Street Type

## Before you start

- Have the **Type** description (e.g., Street, Avenue).
- Check whether the type is not already registered.

## Main flows

1. **Search** — enter the **"Type"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Type** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

## What this screen does not do

- It does not register addresses or streets — only the type used by them.
