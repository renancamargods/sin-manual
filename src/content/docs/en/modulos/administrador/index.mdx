## Overview

The **Administrator** module brings together the general administrative settings of the S.I.N Implant System. It is mainly aimed at those who handle the configuration and maintenance of the environment.

## When to use this module

- Adjust general settings that affect the whole system.
- Track administrative parameters of the environment.

## How to access

Side menu → Modules → Administrator

<Callout type="info" title="Restricted access">
The screens in this module are usually used only by system administrators.
</Callout>
