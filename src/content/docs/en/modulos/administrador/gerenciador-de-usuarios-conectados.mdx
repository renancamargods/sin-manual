## Overview

The **Connected Users Manager** screen shows, in real time, the users currently connected to the system. It presents the **Total of Active Users** and a list with **Name**, **Email** and the **Authenticated at** time.

<Callout type="info" title="Monitoring screen">
This is a lookup-only screen (real-time monitoring). There is no registration or editing — the list updates as users enter and leave the system.
</Callout>

## When to use this screen

- Check how many and which users are connected at the moment.
- Look up each connected user's authentication time.

## How to access

Administrator → Connected Users Manager

## Main flows

1. **Look up** — open the screen and see the **Total of Active Users** and the connected list.
2. **Follow** — the list updates in real time as users enter and leave.

## What this screen does not do

- It does not end sessions or disconnect users — it only shows who is connected.
- It does not register or edit users (that is done in the Authenticator module).
