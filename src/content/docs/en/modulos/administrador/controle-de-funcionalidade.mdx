## Overview

The **Feature Control** screen manages system features through an **Identifier Key**. Each feature can be **Enabled** or not, has a **Value Type** (Boolean, Text, Number or Json) and a corresponding **Value**, plus a **Name** and **Description**. It is the system's *feature flags* mechanism.

<Callout type="cuidado" title="Technical configuration">
Changing a feature changes the system's behavior. Only make changes when you know the key and the expected effect, preferably with support from the technical team.
</Callout>

## When to use this screen

- Register a new feature controlled by a key.
- Enable or disable a feature.
- Adjust a feature's value.

## How to access

Administrator → Feature Control

## Before you start

- Have the feature's **Identifier Key**.
- Know the **Value Type** (Boolean, Text, Number or Json) and the correct **Value**.

## Main flows

1. **Search** — enter the **"Feature Identifier Key"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter **Key**, **Name**, **Description**, the **Value Type** and the **Value**, set **Enabled** and the **System Status** and click **"Save"** (or **"Save and Continue"**).
3. **Edit / enable** — click the **Edit** icon on the row, adjust **Enabled** or the **Value** and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
