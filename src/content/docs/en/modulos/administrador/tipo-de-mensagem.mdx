## Overview

The **Message Type** screen registers the categories that classify the system's **custom messages** (for example, RecusaPedidoCredito, AprovacaoPedidoPadraoAdm, CancelamentoPedido). Each type holds a **Code** and a **Description** and, on the "Custom Messages" tab, gathers the messages that belong to it.

## When to use this screen

- Register a new message type.
- Look up or find a type by code or description.
- Review the custom messages linked to the type.

## How to access

Administrator → Message Type

## Before you start

- Have the type's **code** and **description**.

## Main flows

1. **Search** — enter **Code** or **Description** and click **"Search"**.
2. **Register** — click **"+ New"**, enter **Code** and **Description** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.

- It does not register the messages themselves — that is done on the Custom Message screen (the tab only shows the linked ones).
