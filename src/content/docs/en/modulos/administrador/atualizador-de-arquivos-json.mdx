## Overview

The **JSON File Updater** screen is a **JSON Editor** for the configuration files (**AppSettings**) of the system services. You select the desired file by service group and edit its JSON content.

<Callout type="cuidado" title="Technical screen">
This is a technical screen. Incorrectly editing the configuration files can affect how the system services work. Only make changes when you know the content and, preferably, with support from the technical team.
</Callout>

## When to use this screen

- Look up the content of a JSON configuration file.
- Adjust a service's configuration parameters.

## How to access

Administrator → JSON File Updater

## Before you start

- Know **which file** (service group) you need to edit.
- Know the **content** and the effect of the change.

## Main flows

1. **Select** — in the "Select the json file to edit" field, choose the desired service group.
2. **Look up / edit** — the file content is loaded in the editor for lookup or editing.
3. **Save** — save the changes (confirm that the JSON is valid).

## What this screen does not do

- It does not restart services — it only edits the configuration files.
