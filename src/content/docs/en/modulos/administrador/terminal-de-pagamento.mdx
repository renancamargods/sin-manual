## Overview

The **Payment Terminal** screen registers the terminals (POS devices) used in the units. Each terminal holds a **Description**, the **POS Code** and the **Lounge** it is associated with.

  cards={[

    { label: 'Caution', title: 'POS Code', text: 'The POS code identifies the terminal and must be unique and correct.' },
  ]}
/>

## When to use this screen

- Register a new payment terminal.
- Look up or find a terminal by description or POS code.
- Edit or delete a terminal.

## How to access

Administrator → Payment Terminal

## Before you start

- Have the terminal's **description** and **POS Code**.
- Know which **Lounge** the terminal belongs to.

## Main flows

1. **Search** — enter the filters and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Description**, the **POS Code** and the **Lounge** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
