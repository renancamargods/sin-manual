## Overview

The **Field Validation** screen defines which fields of an **Entity** (Customer, Order or Product), when changed, make the record **go back to review** — Credit, Tax or both. For example, if a customer's address or state registration is changed, the record may return to the corresponding review queue.

## When to use this screen

- Register a field that should trigger review when changed.
- Define the review type (Credit, Tax or Both) for each field.
- Look up, edit or delete configured fields.

## How to access

Administrator → Field Validation

## Before you start

- Define the **Entity** (Customer, Order or Product).
- Know the **field** that triggers the review and the corresponding **review type**.

## Main flows

1. **Search** — enter the **"Name"** and click **"Search"**.
2. **Register** — click **"+ New"**, choose the **Entity**, select the field **Name**, enter the **Description**, set the **Review Type** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
