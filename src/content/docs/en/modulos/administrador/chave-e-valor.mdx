## Overview

The **Key and Value** screen registers configuration **Key** and **Value** pairs, grouped by a **Parameter**. These pairs are used to adjust system behaviors flexibly — for example, defining which blocks appear on the home page for each profile.

<Callout type="cuidado" title="Technical configuration">
Changes here affect the system's behavior. Only make changes when you know the parameter and the expected effect, preferably with support from the technical team.
</Callout>

## When to use this screen

- Look up the key/value pairs of a parameter.
- Register or edit a configuration pair.
- Activate or deactivate a pair.

## How to access

Administrator → Key and Value

## Before you start

- Know which **Parameter** the pair belongs to.
- Have the correct **key** and **value** and know the expected effect.

## Main flows

1. **Search** — enter the filters (Key, Value, Parameter, Status) and click **"Search"**.
2. **Register** — click **"+ New"**, select the **Parameter**, enter **Key** and **Value**, set the **System Status** and click **"Save"**.
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **View history** — click the **History** icon on the row to see the changes.
5. **Delete** — click the **Delete** icon on the row.
