## Overview

The **Parameter** screen registers the general parameters that **group and contextualize** the configuration pairs on the [Key and Value](/en/modulos/administrador/chave-e-valor) screen. Each parameter has a name and a status (Active/Inactive).

  cards={[

/>

## When to use this screen

- Register a new configuration parameter.
- Look up or find a parameter by name.
- Activate or deactivate a parameter.

## How to access

Administrator → Parameter

## Before you start

- Have the parameter's **name**.

## Main flows

1. **Search** — enter the **"Parameter"** and click **"Search"**.
2. **Register** — click **"+ New"**, enter the **Parameter**, set the **System Status** and click **"Save"** (or **"Save and Continue"**).
3. **Edit** — click the **Edit** icon on the row, change it and click **"Save"**.
4. **Delete** — click the **Delete** icon on the row.
