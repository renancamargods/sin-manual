## Overview

The **CE Marking** screen controls the **CE marking** (European conformity) applicable to products. Each record is identified by a **description** and is used in the regulatory control of products intended for the European market.

  cards={[

  ]}
/>

## When to use this screen

- Query the CE marking records.
- Add a new record.
- Fix a record's description.

## How to access

Regulatory → CE Marking

## Before you start

- Have the CE marking record **description**.
- Confirm that your profile allows maintaining this registration.
