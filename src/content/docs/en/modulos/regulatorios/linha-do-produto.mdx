## Overview

The **Product Line** screen keeps the **regulatory lines** associated with products. Each line is identified by its **description** and supports the products' regulatory classification.

  cards={[
    { label: 'Purpose', title: 'Regulatory line', text: 'Keeps the lines used in regulatory classification.' },

    { label: 'Nature', title: 'Support registration', text: 'Queried in the products\' regulatory classification.' },
  ]}
/>

## When to use this screen

- Query the registered regulatory lines.
- Add a new line.
- Fix a line's description.

## How to access

Regulatory → Product Line

## Before you start

- Have the line **description**.
- Confirm that your profile allows maintaining this registration.
