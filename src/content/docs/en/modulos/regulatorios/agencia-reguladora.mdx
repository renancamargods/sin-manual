## Overview

The **Regulatory Agency** screen keeps the list of **regulatory agencies** applicable to products — for example, "ANVISA" (Brazil) and "FDA" (USA). These agencies are used in the products' **regulatory records**.

  cards={[

  ]}
/>

## When to use this screen

- Query the registered regulatory agencies.
- Add a new agency.
- Fix an agency's name.

## How to access

Regulatory → Regulatory Agency

## Before you start

- Have the regulatory agency **name**.
- Confirm that your profile allows maintaining this registration.
