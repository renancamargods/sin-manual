## Overview

The **Manual Rework Label** screen keeps the **manually generated rework label models** (e.g., "EE0034_KIT_A_REV03", "EE0044_COMP_NEST_C"). Each model is identified by a **description** and is used in the manual rework of the products' labels.

## When to use this screen

- Query the manual rework label models.
- Add a new model.
- Fix a model's description.

## How to access

Regulatory → Manual Rework Label

## Before you start

- Have the label model **description**.
- Confirm that your profile allows maintaining this registration.
