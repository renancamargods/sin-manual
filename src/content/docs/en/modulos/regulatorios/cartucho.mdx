## Overview

The **Cartridge** screen keeps the registration of the **cartridges** related to products, identified by the **cartridge code** (e.g., "EC0007"). The cartridges are used in the **cartoning** process and in regulatory traceability.

/>

## When to use this screen

- Query the registered cartridges.
- Add a new cartridge.
- Fix a cartridge's code.

## How to access

Regulatory → Cartridge

## Before you start

- Have the cartridge **code**.
- Confirm that your profile allows maintaining this registration.
