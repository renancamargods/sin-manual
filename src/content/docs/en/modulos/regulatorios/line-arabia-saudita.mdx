## Overview

The **Line — Saudi Arabia** screen keeps the **regulatory line configuration** specific to **Saudi Arabia**. Each record is identified by a **description** and supports the products' regulatory adjustment for that market.

  cards={[

  ]}
/>

## When to use this screen

- Query the Saudi Arabia line records.
- Add a new record.
- Fix a record's description.

## How to access

Regulatory → Line — Saudi Arabia

## Before you start

- Have the record **description**.
- Confirm that your profile allows maintaining this registration.
