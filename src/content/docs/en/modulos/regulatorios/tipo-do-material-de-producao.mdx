## Overview

The **Production Material Type** screen keeps the list of **material types** used in the products' **production**. Each type is identified by a **description** and is used for regulatory classification purposes (for example, the device material).

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Material types', text: 'Keeps the material types used in production.' },
    { label: 'Use', title: 'Description', text: 'Each type is identified by a description.' },
    { label: 'Nature', title: 'Support registration', text: 'Queried in the products\' regulatory classification.' },
  ]}
/>

## When to use this screen

- Query the registered production material types.
- Add a new type.
- Fix a type's description.

## How to access

Regulatory → Production Material Type

## Before you start

- Have the material type **description**.
- Confirm that your profile allows maintaining this registration.
