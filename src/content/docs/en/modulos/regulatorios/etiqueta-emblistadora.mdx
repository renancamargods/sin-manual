## Overview

The **Blister Label** screen keeps the **label models** used in the **blister machine** (blister packaging equipment). Each model is identified by a **description** and is used in generating the labels in the blistering process.

  cards={[

    { label: 'Nature', title: 'Support registration', text: 'Queried in the blistering process.' },
  ]}
/>

## When to use this screen

- Query the blister machine label models.
- Add a new model.
- Fix a model's description.

## How to access

Regulatory → Blister Label

## Before you start

- Have the label model **description**.
- Confirm that your profile allows maintaining this registration.
