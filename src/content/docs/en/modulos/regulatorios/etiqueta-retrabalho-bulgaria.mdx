## Overview

The **Rework Label — Bulgaria** screen keeps the **rework label models** specific to **Bulgaria**. Each model is identified by a **description** and is used in the readjustment (rework) of the products' labels according to that market's regulatory requirements.

## When to use this screen

- Query the Bulgaria rework label models.
- Add a new model.
- Fix a model's description.

## How to access

Regulatory → Rework Label — Bulgaria

## Before you start

- Have the label model **description**.
- Confirm that your profile allows maintaining this registration.
