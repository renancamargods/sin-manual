## Overview

The **Traceability Label** screen keeps the **label models** used for product **traceability** (e.g., "MDR_CP_NST_A_R03", "NOT APPLICABLE"). Each model is identified by a **description** and is used in generating the traceability labels.

    { label: 'Nature', title: 'Support registration', text: 'Queried in label generation.' },
  ]}
/>

## When to use this screen

- Query the traceability label models.
- Add a new model.
- Fix a model's description.

## How to access

Regulatory → Traceability Label

## Before you start

- Have the label model **description**.
- Confirm that your profile allows maintaining this registration.
