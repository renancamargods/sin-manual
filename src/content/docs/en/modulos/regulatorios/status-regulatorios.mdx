## Overview

The **Regulatory Status** screen keeps the list of **statuses** used to indicate the products' current **regulatory situation**. Each status is identified by a **description** and is applied to the products to track their situation with the regulatory bodies.

/>

## When to use this screen

- Query the registered regulatory statuses.
- Add a new status.
- Fix a status's description.

## How to access

Regulatory → Regulatory Status

## Before you start

- Have the status **description**.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not change the product's actual situation with the body — it only maintains the list of statuses.
