## Overview

The **Product Connection** screen keeps the list of **connections** associated with products — for example, "CM" (Morse Taper), "HE" (External Hex) and "HI" (Internal Hex). The connection is used in the **classification** of implants, including for regulatory purposes.

    { label: 'Nature', title: 'Support registration', text: 'Queried in regulatory classification.' },
  ]}
/>

## When to use this screen

- Query the registered connections.
- Add a new connection.
- Fix a connection's description.

## How to access

Regulatory → Product Connection

## Before you start

- Have the connection **description**.
- Confirm that your profile allows maintaining this registration.
