## Overview

The **Commercial Classification** screen keeps the **commercial classifications** (identified by a **code**, e.g., "A", "B", "C", "Platinum") used in **commercial policies**. Each classification can have its own **customer list**.

## When to use this screen

- Query the registered commercial classifications.
- Create a new classification.
- Associate customers with a classification.

## How to access

Customers → Commercial Classification

## Before you start

- Define the classification **code**.
- Know which **customers** belong to it, if applicable.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not define prices or discounts by itself — it only classifies commercially.
- It does not register the customers — they come from the Customer registration.
