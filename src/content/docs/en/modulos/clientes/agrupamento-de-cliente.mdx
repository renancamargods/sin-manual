## Overview

The **Customer Grouping** screen lets you gather several **customers** under the same **grouping** (identified by a description). This grouping is used in **analyses** and in **commercial rules**, making it easier to handle a set of customers together.

## When to use this screen

- Create a grouping to handle a set of customers together.
- Add or remove customers from a grouping.
- Query the groupings already registered.
- Activate or deactivate a grouping.

## How to access

Customers → Customer Grouping

## Before you start

- Know which **customers** will be part of the grouping.
- Define a clear **description** to identify the grouping.
- Confirm that your profile allows registering groupings.

## Main flows

1. **Create the grouping** — click **"+ New"** and inform the "Description".
2. **Add customers** — in the "Customers" tab, use **"Add Customer - Quick Entry"** to include the customers.
3. **Save** — use **"Save"** (or "Save and Continue" to keep editing).

## What the screen does not do

- It does not register the customers — they come from the Customer registration.
- It does not, by itself, define prices or discounts — it only groups customers.
