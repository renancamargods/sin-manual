## Overview

The **Consumption Profile** screen keeps the **consumption profiles** used to classify customers according to their buying behavior — for example, "Frequent", "Not Frequent", "Inactive", "New", "Recovered" and "Active Distributor". These profiles are used in **planning and goals**. Each profile can have its own **customer list**.

## When to use this screen

- Query the registered consumption profiles.
- Create a new consumption profile.
- Associate customers with a profile.

## How to access

Customers → Consumption Profile

## Before you start

- Define the profile **description**.
- Know which **customers** belong to it, if applicable.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not calculate consumption — it only maintains the profiles and the customer association.
- It does not register the customers — they come from the Customer registration.
