## Overview

The **Customer Attachment** screen stores the **documents (attachments)** linked to a **customer** — for example, receipts, photo IDs and records. Each attachment has the **file**, a **description** and **keywords** that help locate it.

## When to use this screen

- Attach a document to a customer's registration.
- Query or download a customer's attachments.
- Locate an attachment by customer, description or file name.

## How to access

Customers → Customer Attachment

## Before you start

- Have the **file** that will be attached.
- Know which **customer** the attachment belongs to.
- Confirm that your profile allows attaching documents.

<Callout type="cuidado" title="Personal data">
Attachments may contain customers' personal documents. Handle the files carefully and follow the company's privacy rules.
</Callout>

## Main flows

1. **Attach** — click **"+ New"**, use **"Choose file"** and inform the description, keywords and customer.
2. **Save** — click **"Save"**.
3. **Query/download** — in the listing, use the row icons to download or see the details.

## What the screen does not do

- It does not register the customer — it comes from the Customer registration.
- It does not edit the file content — it only stores and links it.
