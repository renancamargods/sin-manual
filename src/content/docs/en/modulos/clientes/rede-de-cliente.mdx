## Overview

The **Customer Network** screen gathers the **customers that belong to the same network** (identified by a **description**). The network makes it easier to handle together the customers of the same brand/commercial group and is used in analyses and commercial rules. Each network has its own **customer list**.

## When to use this screen

- Create a network to gather related customers.
- Query the registered networks.
- Add or remove customers from a network.

## How to access

Customers → Customer Network

## Before you start

- Define the network **description**.
- Know which **customers** will be part of it.
- Confirm that your profile allows maintaining this registration.

## Main flows

1. **Create the network** — click **"+ New"** and inform the "Description".
2. **Add customers** — in the "Customers" tab, use **"Add Customer - Quick Entry"**.
3. **Save** — use **"Save"** (or "Save and Continue").

## What the screen does not do

- It does not register the customers — they come from the Customer registration.
- It does not define prices or discounts by itself — it only groups customers by network.
