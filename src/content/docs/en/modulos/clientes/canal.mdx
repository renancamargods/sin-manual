## Overview

The **Channel** screen keeps the list of **sales channels** associated with customers — for example, "Retail", "Distributor", "Key Account" and "International". The channel helps to **classify** the customer and is used in commercial rules and analyses.

## When to use this screen

- Query the registered channels.
- Add a new sales channel.
- Fix the description of a channel.

## How to access

Customers → Channel

## Before you start

- Define the channel **description**.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not classify the customer automatically — it only maintains the list of channels.
- It does not define prices or discounts by itself.
