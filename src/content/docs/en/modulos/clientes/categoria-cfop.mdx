## Overview

The **CFOP Category** screen keeps the **CFOP categories** used in the customers' **fiscal operations** — for example, "Agricultural Customer", "Exempt Customer", "Service Provision" and "Transport". Each category has a **code** and a **description**, and helps define the fiscal treatment applied to the customer.

## When to use this screen

- Query the registered CFOP categories.
- Add a new CFOP category.
- Fix the code or description of a category.

## How to access

Customers → CFOP Category

## Before you start

- Have the **code** and the **description** of the CFOP category.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not define the CFOPs themselves — only the categories used in the classification.
- It does not change invoices.
