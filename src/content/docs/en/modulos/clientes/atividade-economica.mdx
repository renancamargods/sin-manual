## Overview

The **Economic Activity** screen keeps the list of **economic activities** (in the **CNAE** standard) used to **classify customers**. Each activity has a **code** (e.g., "0111-3/01") and a **description** (e.g., "Rice growing").

## When to use this screen

- Query the registered economic activities.
- Add a new economic activity.
- Fix the code or description of an activity.

## How to access

Customers → Economic Activity

## Before you start

- Have the **CNAE code** and the **description** of the activity.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not classify customers automatically — it only maintains the list of activities.
- It does not change the customer's fiscal data.
