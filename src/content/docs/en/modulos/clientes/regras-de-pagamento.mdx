## Overview

The **Payment Rules** screen defines **which payment methods and conditions** are released for each **customer**. Each rule links a **Customer** to a **Payment Method** and, optionally, to one or more **Payment Conditions**, and can further be scoped by **Company**, **Center**, **Smart Operation** and **Operation Type**.

This is how the system limits, on the order, the payment options to what was authorized for the customer.

## When to use this screen

- Release a payment method/condition for a customer.
- Restrict a customer's payment to specific conditions.
- Apply the same payment rule to several customers at once.

## How to access

Customers → Payment Rules

## Before you start

- Know the **customer** (or the list of customers, for batch registration).
- Have the **Payment Method** defined and, if applicable, the **Payment Conditions** to release.

## Main flows

1. **Query** — enter the filters and search the registered rules.
2. **Register (individual)** — click **"+ New"**, select the **Customer**, the **Payment Method** and the **Conditions**, adjust the optional scopes and **save**.
3. **Register in batch** — choose the list of customers and the rule, check the **preview** and confirm.
4. **Edit / Delete** — use the row actions to change or remove a rule.

## What this screen does not do

- It does not create payment methods or conditions — that is done in the Policies module; here they are only **released** per customer.
