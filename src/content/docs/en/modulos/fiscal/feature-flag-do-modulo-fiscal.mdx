## Overview

The **Tax Module Feature Flag** screen controls the **activation of tax module features** gradually. Each record defines a **status** (Disabled, Shadow or Active), a **validity** and the **scope** of application — by **states**, **customers** and **fiscal operation types**.

## When to use this screen

- Activate or test (Shadow) a tax feature in a controlled way.
- Define the scope of application by states, customers and operation types.
- Look up or change the validity and status of a feature flag.
- Synchronize the feature flags with "Sincronizar Agora".

## How to access

Tax → Tax Module Feature Flag

## Before you start

- Define the desired **status**: Disabled, Shadow (validation with no effect) or Active.
- Know the **scope**: which states, customers and fiscal operation types are affected.
- Have the **validity** dates (start and, when applicable, end).

## Main flows

1. **Search** — enter the "Description" and click **"Search"**.
2. **Register** — click **"+ New"**, fill in the "Information" (description, status, validity) and define the scope (States, Customers, Fiscal Operation Types); click **"Save"**.
3. **Edit** — use the row's **Edit** icon, adjust the data and click **"Save"**.
4. **Synchronize** — use **"Sincronizar Agora"** to synchronize the feature flags.

## What this screen does not do

- Does not change the tax rules themselves — it only controls the activation of features by scope and validity.
- Does not register states, customers or operation types — it only links them to the scope.
