## Overview

The **Access Sequence** screen registers the **access sequences** used in the fiscal calculation. Each sequence is linked to a **tax type** and holds **steps** that define, in order, the criteria for applying the rules (by origin state, destination state, material origin and the customer's industrial sector).

## When to use this screen

- Register a new access sequence for a tax type.
- Look up the access sequences already registered.
- Change the steps or the status of a sequence.
- Deactivate a sequence that should no longer be used.

## How to access

Tax → Access Sequence

## Before you start

- Know the **tax type** the sequence will be linked to.
- Define the **steps** and the **order** in which they will be applied.
- Know the criteria of each step (origin state, destination state, material origin, customer's industrial sector).

## Main flows

1. **Search** — enter the "Name" and click **"Search"**.
2. **Register** — click **"+ New"**, fill in the "Information" (name, tax type, active) and add the steps with **"+ New Step"**; click **"Save"**.
3. **Edit** — use the row's **Edit** icon, adjust the data and the steps and click **"Save"**.
4. **Look up details** — use the **Details** icon to see the information.

## What this screen does not do

- Does not register the tax types — that is done on the Tax Type screen.
- Does not calculate the taxes — it only defines the access sequence used in the calculation.
