## Overview

The **Tax Type** screen holds the registration of the tax types used in the system operations (e.g., "ICMS Interestadual", "DIFAL", "ICMS Contribuinte"). Each type defines the **calculation mode** (inside or outside), the **calculation order** and the **validity**.

## When to use this screen

- Register a new tax type.
- Look up the tax types already registered.
- Change the mode, calculation order or validity of a tax.
- Deactivate a tax type that should no longer be used.

## How to access

Tax → Tax Type

## Before you start

- Know the calculation **mode** of the tax ("Por Dentro"/inside or "Por Fora"/outside).
- Define the **calculation order** relative to the other taxes.
- Have the **validity** dates (start and, when applicable, end).

## Main flows

1. **Search** — enter the "Name" and click **"Search"**.
2. **Register** — click **"+ New"**, fill in the fields and click **"Save"**.
3. **Edit** — use the row's **Edit** icon, adjust the fields and click **"Save"**.
4. **Look up details** — use the **Details** icon to see the information.
5. **Deactivate or delete** — change the "Active" field in the edit window, or use the **Delete** icon (red X).

## What this screen does not do

- Does not calculate the operation taxes — it only registers the types used in the calculation.
- Does not define the access sequences — that is done on the Access Sequence screen.
