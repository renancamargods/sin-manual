## Overview

The **Product Image** screen stores the **images** linked to the **products**. Each image has the **file**, a **type**, **keywords** and the **product** it belongs to, and is used to display the products (for example, in catalogs).

## When to use this screen

- Link an image to a product.
- Query the images by name, keywords, type or product.
- Fix or replace a product's image.

## How to access

Products → Product Image

## Before you start

- Have the image **file**.
- Know the **type** and the **product** the image belongs to.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not register the product — it only links the image to it.
- It does not edit the image — it only stores and links it.
