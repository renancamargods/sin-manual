## Overview

The **Milling Set** screen registers the **milling sets** used in the procedures: each set has a **description**, is associated with a **surgical kit** and gathers its **milling burs** and **implants**.

  cards={[

    { label: 'Nature', title: 'Support registration', text: 'Queried in the registration and use of products.' },
  ]}
/>

## When to use this screen

- Query the registered milling sets.
- Create a new milling set.
- Associate milling burs and implants with a set.

## How to access

Products → Milling Set

## Before you start

- Define the set **description** and the **surgical kit**.
- Know which **milling burs** and **implants** make up the set.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not register the milling burs or implants — they come from the product registration.
- It does not control stock — it only organizes the set.
