## Overview

The **Product Type** screen keeps the **types** used to classify the products — for example, "Implant", "Biomaterials", "Prosthetic Component" and "Kits and Instruments". Each type has a **code** and a **description**.

## When to use this screen

- Query the registered product types.
- Add a new type.
- Fix the code or description of a type.

## How to access

Products → Product Type

## Before you start

- Have the type **code** and **description**.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not classify products automatically — it only maintains the list of types.
