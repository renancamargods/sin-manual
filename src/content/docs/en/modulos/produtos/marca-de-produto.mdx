## Overview

The **Product Brand** screen keeps the **brands** associated with products (e.g., "SIN", "Singular"). Each brand has a **code** and a **description**, and helps to classify the products.

  cards={[

  ]}
/>

## When to use this screen

- Query the registered brands.
- Add a new brand.
- Fix the code or description of a brand.

## How to access

Products → Product Brand

## Before you start

- Have the brand **code** and **description**.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not classify products automatically — it only maintains the list of brands.
