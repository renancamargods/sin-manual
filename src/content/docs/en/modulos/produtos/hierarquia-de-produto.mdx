## Overview

The **Product Hierarchy** screen builds the **hierarchical structure** (tree) used to **organize products by levels**. Each node has a **title**, a **level**, a **parent** and can have **children**, besides the **products** and an **image**. This structure is used, for example, in the **catalog app**.

## When to use this screen

- Build or adjust the product hierarchy.
- Define the levels, parents and children of the structure.
- Associate products with a hierarchy node.

## How to access

Products → Product Hierarchy

## Before you start

- Plan the structure (levels, parents and children).
- Know which **products** go in each node.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not register the products — it only organizes them in the hierarchy.
- It does not control stock or prices.
