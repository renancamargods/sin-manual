## Overview

The **Packaging Box** screen keeps the registration of the **boxes** used to pack products. Each box is identified by a **code** and has a **volume**, used in dispatch and in the calculation of shipment volumes.

  cards={[

## When to use this screen

- Query the registered packaging boxes.
- Add a new box.
- Fix the code or the volume of a box.

## How to access

Products → Packaging Box

## Before you start

- Have the box **code** and **volume**.
- Confirm that your profile allows maintaining this registration.

## What the screen does not do

- It does not register the products — only the packaging boxes.
- It does not calculate freight — it only keeps the box volume.
