## Overview

The **Leads Kanban Board** shows the leads in a **visual panel (kanban)**, organized in **columns by Sales Pipeline status**. There is **one column for each status** of the selected pipeline, in the order defined in it — for example, the "SIN Solutions" pipeline has 12 columns (from "New - No Interaction" to "Won" and "Lost"), so the board **scrolls horizontally** to show them all. Each column displays the **total potential value** and the **number of leads** in that stage. Leads appear as cards and can be moved between columns as they advance in the funnel.

## When to use this screen

- Visually track the leads by funnel stage.
- See the total potential value and the number of leads in each stage.
- Move a lead from one stage to another as the service advances.

## How to access

Leads → Leads Kanban Board

## Before you start

- Have a **Sales Pipeline** registered (the board columns are the stages of that pipeline).
- Select the **Sales Pipeline** in the filter for the board to build the columns.

<Callout type="info">
When opening the screen without a chosen pipeline, the board shows the message **"Pipeline Not Selected"**. Select a Sales Pipeline in the filter to view and manage the leads.
</Callout>

## Main flows

1. **Select the pipeline** — choose the **"Sales Pipeline"** in the filter for the board to build the columns.
2. **Search** — adjust the other filters and click **"Search"**.
3. **Move the lead** — drag the lead card from one column to another to change the stage.
4. **Register** — use **"+ New"** to record a lead referral (same window as Lead Referral).

## Relationship with other processes

- **Sales Pipeline** — defines the stages that become the board columns.
- **Lead Referral** — registers the leads shown on the board.

## What this screen does not do

- It does not define the stages — the stages (columns) come from the Sales Pipeline.
- It does not display columns without a selected pipeline.
