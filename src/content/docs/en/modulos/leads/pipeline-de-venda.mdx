## Overview

The **Sales Pipeline** screen gathers the registration of the **sales pipelines (funnels)** and their **stages**. Each pipeline has a name, a description and a set of **stages** ("Pipeline Status"), with **probability** and **order**. These stages are the **columns of the Leads Kanban Board** and the steps the leads advance through.

## When to use this screen

- Register a new sales pipeline.
- Define or adjust the stages of a pipeline.
- Check the pipelines already registered.

## How to access

Leads → Sales Pipeline

## Before you start

- Define the funnel **stages** and the **order** in which they occur.
- Define the closing **probability** associated with each stage.

<Callout type="info" title="Example — 'SIN Solutions' pipeline">
The default pipeline has **12 statuses**, grouped into two stages: **Negotiation** (New - No Interaction, Lead, Did Not Reply, Online Presentation, In-Person Presentation, Proposal Sent, Stand By, Financial Analysis, Financial Pending Items, Awaiting Signature) and **Closing** (Won, Lost). Each one has its own probability % and order.
</Callout>

## Main flows

1. **Search** — click **"Search"** to list the pipelines.
2. **Register** — click **"+ New"**, enter "Name" and "Description", register the stages in **"+ New Pipeline Status"** and click **"Save"**.
3. **Edit** — use the **Edit** icon on the row, adjust the data or the stages and click **"Save"**.
4. **View details** — use the **Details** icon.

## Relationship with other processes

- **Leads Kanban Board** — uses the pipeline stages as columns.
- **Lead Referral** — associates each lead with a pipeline.

## What this screen does not do

- It does not move the leads — movement between stages is done on the Leads Kanban Board.
