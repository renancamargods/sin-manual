## Overview

The **Contract Attachment** screen gathers the **documents attached to contracts**. Each attachment is a **file** (for example, a PDF) with **keywords**, a **description** and the **contract** it is linked to.

## When to use this screen

- Attach a document to a contract.
- View and download the documents already attached.
- Locate an attachment by name or by keywords.

## How to access

Contracts → Contract Attachment

## Before you start

- Have the **file** to be attached.
- Know the **contract** the attachment belongs to.

## Main flows

1. **Search** — enter "Name" or "Keywords" and click **"Search"**.
2. **Attach** — click **"+ New"**, choose the file, fill in the fields and click **"Save"**.
3. **Download** — use the **Download** icon on the row.
4. **Edit** — use the **Edit** icon on the row, adjust the fields and click **"Save"**.

## Relationship with other processes

- **Contract** — the attachments are linked to the contracts registered on the Contract screen.

## What this screen does not do

- It does not create the contract — it only links the document to an existing contract (or lets you register a new one via the "+").
