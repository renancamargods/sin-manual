## Overview

The **Course Period** screen gathers the **periods of the course classes** — that is, the **day of the week** and the **start and end times** when the class takes place. Each period is linked to a **class**.

## When to use this screen

- Register the day and time of a course class.
- View the periods already registered.
- Change the day or the times of a period.

## How to access

Contracts → Course Period

## Before you start

- Know the **class** the period belongs to.
- Define the **day of the week** and the **start and end times**.

## Main flows

1. **Search** — select the "Class" and click **"Search"**.
2. **Register** — click **"+ New"**, enter the day, the times and the class and click **"Save"**.
3. **Edit** — use the **Edit** icon on the row, adjust the fields and click **"Save"**.
4. **View details** — use the **Details** icon.

## Relationship with other processes

- **Course Class** — the periods belong to the classes registered on the Course Class screen (which also allows registering the periods in the "Periods" tab).

## What this screen does not do

- It does not register the class — only the periods; the class is registered on the Course Class screen.
