## Overview

The **Course Class** screen gathers the **course classes linked to contracts**. Each class has the **course data** (type, name, institution, dates, contract), the list of **participants** and the **periods** (days and times) when it takes place.

## When to use this screen

- Register a new course class.
- View the classes already registered.
- Manage the participants and the periods of a class.

## How to access

Contracts → Course Class

## Before you start

- Know the **course type** and the **contract** the class belongs to.
- Have the **start and end dates** and the **educational institution**.

## Main flows

1. **Search** — enter the filters and click **"Search"**.
2. **Register** — click **"+ New"**, fill in the course data, the participants and the periods and click **"Save"**.
3. **Edit** — use the **Edit** icon on the row, adjust the tabs and click **"Save"**.
4. **Export** — use the **"Detailed Excel of Course Classes"** button.

## Relationship with other processes

- **Course Period** — the class periods can also be viewed and registered on the Course Period screen.
- **Contract** — the class is linked to a contract.

## What this screen does not do

- It does not sign the contract — it links the class to an existing contract (or lets you register a new one via the "+").
