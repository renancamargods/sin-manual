## Overview

The **Consumption Target** screen gathers the **consumption targets set in a contract**. Each target defines a **quantity**, the **contract** it belongs to and the **item scope** — that is, whether the target applies to a "Product Type", a "Product Family", a "Product Group" or a "Product".

## When to use this screen

- Register a consumption target for a contract.
- View the consumption targets already registered.
- Change the quantity or the scope of a target.

## How to access

Contracts → Consumption Target

## Before you start

- Know the **contract** the target belongs to.
- Define the target **quantity** and the **item scope** (type, family, group or product).

## Main flows

1. **Search** — click **"Search"** to list the targets.
2. **Register** — click **"+ New"**, enter the quantity, the contract and the item scope and click **"Save"**.
3. **Edit** — use the **Edit** icon on the row, adjust the fields and click **"Save"**.
4. **View details** — use the **Details** icon.
