## Overview

The **Approvals** module defines which information must go through approval before continuing in other processes, and who is responsible for approving each situation. It is used together with other modules, such as Orders and Contracts.

## When to use this module

- Define what needs approval.
- Configure who approves each type of request.
- Look up the approval rules already registered.

## How to access

Side menu → Modules → Approvals

<Callout type="info" title="Combined use">
The rules registered here apply to the processes of other modules that use approval, such as orders and contracts.
</Callout>
