## Overview

The **Approval Queue - Orders** screen (shown as "New Order Approval Queue") is where the responsible groups **decide on the orders** sent for approval. Each order awaiting release appears in a list, with the status, the cycle progress, the block reasons and the actions to **approve**, **reject** or **send for evaluation**.

The screen organizes the work in three tabs — **"Orders to Release"**, **"Orders in Evaluation"** and **"Rejected"** — and shows **totals** with the quantity and value of the orders awaiting approval.

## When to use this screen

- Check the orders awaiting your approval.
- Approve an order so it advances in the cycle.
- Reject an order that does not meet the requirements.
- Send an order for evaluation when it needs analysis before deciding.
- Track the quantity and value of the orders in the queue.

## How to access

Approvals → Approval Queue - Orders

## Before you start

- Confirm that your group is responsible for the cycle stage of these orders.
- Consider the **priority**, the **value** and the **block reasons** when deciding.

## Main flows

1. **Locate the order** — enter the filters and click **"Search"**.
2. **Choose the tab** — use **"Orders to Release"**, **"Orders in Evaluation"** or **"Rejected"**.
3. **Review the order** — check value, priority and block reasons before deciding.
4. **Decide** — on the order row, use **Approve**, **Reject** or **Send for evaluation**.
5. **Track** — the totals and the status of each row show the progress.

<Callout type="cuidado" title="Check before deciding">

## What this screen does not do

- It does not create or send orders — that is done on the Order screen.
- It does not change the approval rules or define who the approvers are.
