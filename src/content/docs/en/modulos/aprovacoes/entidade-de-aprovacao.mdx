## Overview

The **Approval Entity** screen is where you register the entities that use the system’s **generic approval model**. Each entity represents a type of item that can be submitted for approval — for example, **Customer** and **Order**.

Once registered, the entity receives its **approval rules** (on the Approval Rule screen), which define who approves and under which conditions. Currently Customer and Order are registered; Contracts is planned to be added.

<Callout type="dica" title="Generic approval model">
With this model, making a new item approvable is simpler and configurable: just register the entity here and then define its approval rules — without needing a specific implementation for each case.
</Callout>

## When to use this screen

- Register a new approval entity.
- Look up the entities already registered.
- Activate or inactivate an entity.
- Edit the name or status of an entity.

## How to access

Approvals → Approval Entity

## Before you start

- Define the name of the entity that will be submitted for approval.
- Check whether the entity is not already registered.
- After registering, configure the entity’s approval rules on the Approval Rule screen.

## Main flows

1. **Look up** — enter the Name and/or Status and click **"Search"**.
2. **View details** — click the **View/Detail** icon on the row.
3. **Register an entity** — click **"+ New"**, enter the **Name**, set the **System Status** and click **"Save"**.
4. **Edit an entity** — click the **Edit** icon, change the fields and click **"Save"**.
5. **Activate / inactivate** — in the registration, adjust the **System Status** and save.
6. **Delete an entity** — click the **Delete** icon on the row.
7. **View history** — click the **History** icon to track the entity’s changes.

## What the screen does not do

- It does not define who approves nor the conditions — that is done on the Approval Rule screen.
- It does not approve items — it only registers the entities that can be approved.
