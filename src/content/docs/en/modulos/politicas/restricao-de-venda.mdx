## Overview

The **Sales Restriction** screen gathers the registration of the **restrictions** applied to certain sales. Each restriction has a **type**, a **validity** and a **segmentation** (customer, lounge, state, line of business, channel, order type, user group) that defines where the restriction applies.

## When to use this screen

- Register a new sales restriction.
- Check the restrictions already registered.
- Adjust the type, the validity or the segmentation of a restriction.

## How to access

Policies → Sales Restriction
