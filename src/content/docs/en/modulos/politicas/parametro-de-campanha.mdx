## Overview

The **Campaign Parameter** screen gathers the registration of the **parameters** used in **commercial campaigns**. Each parameter has a **title**, may have a **parent parameter** (hierarchy), an **availability period** (availability date and "show until") and the **end of path** flag.

## When to use this screen

- Register a new campaign parameter.
- Check the parameters already registered.
- Organize the parameters in a hierarchy (parent/child).

## How to access

Policies → Campaign Parameter
