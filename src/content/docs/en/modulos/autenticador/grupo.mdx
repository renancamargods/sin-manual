## Overview

The **Group** screen holds the registration of the system groups. A group **gathers users**, **links one or more profiles** and lets you **define access permissions** by URL, organized by module.

Together with the Profile, the group is part of access control: it organizes users and defines, for each screen (URL), what the group can look up, add, delete and more.

## When to use this screen

- Register a new group.
- Look up the existing groups and their details.
- Link or remove users and profiles from a group.
- Define or review the group access permissions by URL and module.
- Look up the change log of a group.

## How to access

Authenticator → Group

## Before you start

- Confirm which users and profiles should make up the group.
- Know which screens (URLs) and permissions the group should have in each module.
- Check whether an equivalent group already exists before creating a new one.

## Main flows

1. **Find a group** — enter the "Name" and click **"Search"**.
2. **Create a group** — click **"+ New"**, enter the "Name", add the "Users" and the "Profiles" and click **"Save"**.
3. **Edit a group** — use the row's **Edit** icon, adjust "Name", "Users" or "Profiles" and click **"Save"**.
4. **Define permissions** — use the **Define access permissions** icon, choose the module and adjust the permissions by URL.
5. **Look up the log** — use the **Change log** icon to see who changed the group and when.
6. **Delete a group** — use the row's **Delete** icon (red X).

## What this screen does not do

- Does not register users — that is done on the User screen.
- Does not create profiles — that is done on the Profile screen.
- Does not register the URLs — they are maintained on the URL screen; here you only define the group permissions over them.
