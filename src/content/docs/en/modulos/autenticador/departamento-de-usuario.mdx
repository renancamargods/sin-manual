## Overview

The **User Department** screen gathers the registration of the **departments** that group users by **company area**. Each department is linked to a **directorate**.

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Department registration', text: 'Organizes users by company area.' },
    { label: 'Use', title: 'Internal structure', text: 'Relates each department to its directorate.' },
    { label: 'Caution', title: 'Correct directorate', text: 'Link the department to the corresponding directorate.' },
  ]}
/>

## When to use this screen

- Register a new department.
- Check the departments already registered.
- Change the directorate of a department.

## How to access

Authenticator → User Department
