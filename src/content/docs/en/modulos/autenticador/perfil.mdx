## Overview

The **Profile** screen gathers the registration of the **access profiles** (e.g., "Administrator", "FVE Consultant", "Coordinator"). Each profile has a **title** and groups one or more permission **groups**, which define what the user can access in the system.

  cards={[
    { label: 'Purpose', title: 'Profile registration', text: 'Groups permission groups into an access profile.' },

    { label: 'Caution', title: 'Correct groups', text: 'Associate the groups that match the profile permissions.' },
  ]}
/>

## When to use this screen

- Register a new access profile.
- Check the profiles already registered.
- Change the groups associated with a profile.

## How to access

Authenticator → Profile

## Relationship with other processes

- **Group** — profiles group the permission groups.
- **User** — the profile is assigned to the user to define their access.

## What this screen does not do

- It does not register the users — only the profiles; users are registered on the User screen.
