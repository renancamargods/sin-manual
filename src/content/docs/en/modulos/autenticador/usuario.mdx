## Overview

The **User** screen brings together the registration of the people who access the S.I.N Implant System, associating each one with an access profile, a department and, when applicable, one or more groups.

It is through this registration that you define who can enter the system and, together with the Profile, what each person can see and do.

## When to use this screen

- Register a new user.
- Look up the access data of an existing user.
- Change a user’s profile, department or group.
- Block or inactivate a user’s access.

## How to access

Authenticator → User

## Before you start

- Confirm the appropriate access profile for the person’s role.
- Check whether the person does not already have a user registration.
- Have at hand a valid corporate email, used for login and password recovery.

## Main flows

1. **Register a new user** — fill in the required data, associate a profile and save.
2. **Look up a user** — use the search to find it by name or email.
3. **Change a user** — update profile, department or group as needed.
4. **Inactivate a user** — change the status to inactive when the person no longer needs access.

## Relationships with other records or processes

This record depends on a profile already configured on the Profile screen and can be organized by department and group. The access history can be looked up on the Login Attempt screen.

<Callout type="cuidado" title="Direct impact on access">
Changing a user’s profile immediately changes what they can see and do in the system.
</Callout>

## Important parameters and behaviors

- The user must be active to access the system.
- The profile change applies on the user’s next access.
- Inactive users cannot log in, but their history is kept.

## Rules and cautions

- Register only people authorized by the company.
- Avoid duplicating registrations for the same person.
- Prefer to inactivate rather than delete a user who already has usage history.
- Review the assigned profile whenever the person’s role changes.
