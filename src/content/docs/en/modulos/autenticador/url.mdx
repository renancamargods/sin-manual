## Overview

The **URL** screen gathers the registration of the system **addresses (URLs)**. Each address has a **name**, the corresponding **module** and **controller**, plus the **Active** and **Visible** flags. These addresses are used in **access control** and system navigation.

  cards={[

  ]}
/>

## When to use this screen

- Register a new system address (URL).
- Check the addresses already registered.
- Adjust the module, the controller or the flags of an address.

## How to access

Authenticator → URL

- **Profile** — the addresses are used in the access control associated with the profiles.
