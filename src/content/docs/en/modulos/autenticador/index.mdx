## Overview

The **Authenticator** module controls who accesses the system and what each person can do. Here you find the records of users, access profiles, groups and the history of login attempts.

## When to use this module

- Register or change a user.
- Configure an access profile and its permissions.
- Look up login attempts.
- Organize users by department or group.

## How to access

Side menu → Modules → Authenticator

<Callout type="cuidado" title="Broad impact">
Changes in this module directly affect what other users can see and do in the system. Review carefully before saving.
</Callout>
