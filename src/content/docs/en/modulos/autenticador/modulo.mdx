## Overview

The **Module** screen gathers the registration of the **modules** available in the system. Each module has a **name** and an **address bar display** (the text used in the module URL).

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Module registration', text: 'Registers the modules available in the system.' },
    { label: 'Use', title: 'System organization', text: 'Modules group the screens and are used in access control.' },
    { label: 'Caution', title: 'URL display', text: 'The "address bar display" makes up the module address.' },
  ]}
/>

## When to use this screen

- Register a new module.
- Check the modules already registered.
- Adjust the name or the address bar display of a module.

## How to access

Authenticator → Module
