## Overview

The **Login Attempt** screen lets you **query the system login attempt history**. Each record shows the **e-mail** used, the **attempt date** and the **status** (whether the attempt succeeded or not). It is a **query** screen, useful for tracking and security.

  cards={[

    { label: 'Caution', title: 'Query only', text: 'The screen does not register or change records; it only queries.' },
  ]}
/>

## When to use this screen

- Query the login attempts of a user (by e-mail).
- Check attempts in a period.
- Track the status of the attempts (success or failure).

## How to access

Authenticator → Login Attempt

## What this screen does not do

- It does not register or change records — it is a query screen.
- It does not block or release accesses — it only shows the history.
