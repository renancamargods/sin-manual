## Overview

The **Sales Planning** module supports the definition of targets and expected sales volumes, serving as a reference for commercial tracking.

## When to use this module

- Register a new sales plan.
- Look up targets set for a period.

## How to access

Side menu → Modules → Sales Planning

<Callout type="info" title="Comparative use">
The plan registered here is usually used as a reference to compare with the actual sales volume.
</Callout>
