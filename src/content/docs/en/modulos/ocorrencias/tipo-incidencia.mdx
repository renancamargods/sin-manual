## Overview

The **Incidence Type** screen gathers the registration of the **incidence types** used to **classify occurrences**. Each type has a description, a **grounds for non-validity** and an **other information** field.

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Type registration', text: 'Classifies occurrences by incidence type.' },
    { label: 'Use', title: 'Standardization', text: 'Standardizes the classification used in occurrences.' },
    { label: 'Caution', title: 'Grounds', text: 'Fill in the grounds for non-validity when applicable.' },
  ]}
/>

## When to use this screen

- Register a new incidence type.
- Check the types already registered.
- Adjust the grounds or the information of a type.

## How to access

Occurrences → Incidence Type
