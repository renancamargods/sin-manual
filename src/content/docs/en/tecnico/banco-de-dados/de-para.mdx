## Overview

A **De/Para** is a translation table: for each value used in CrmSin, it states the equivalent value expected by another system. In the S.I.N Implant System, De/Para tables serve mainly the **SAP S/4HANA integration** — they convert CRM records (customer, order, plant, payment terms) into the *customizing* codes that SIN's SAP actually uses.

<QuickCards
  cards={[
    { label: 'Purpose', title: 'Translate codes', text: 'Converts CrmSin values into the codes SAP and the legacy integrator expect.' },
    { label: 'Usage', title: 'DBA and integration', text: 'Used by the database, support and integration teams when investigating mismatches.' },
    { label: 'Caution', title: 'Customer customizing', text: 'These are SIN-internal values; changing them without the SAP team breaks the integration.' },
  ]}
/>

<Callout type="atencao" title="Not a system screen">
There is no "De/Para" screen in CrmSin. These mappings live partly in the integration **code** (class `MontadorDadosClienteSap` and `PedidoCapa` rules) and partly in **database records/tables** (for example `Pedidos_OperacaoInteligente` and `Administrador_Centro`). The values below were extracted from the legacy RFC/BAPI integrator and **confirmed against the homologation database**.
</Callout>

## System enums (database code → meaning)

Every enum in the system is stored in the database as an **integer**. The tables below, organized by module, are the De/Para between the stored value, the technical enum name and the meaning shown to the user (when a label exists). Source: `CrmSin.Domain.Entities/<Module>/Models/Enums`; meanings come from the `SharedResource.en-US` resources.

<Callout type="cuidado" title="Before reading a number">
The same number means different things in different enums — always confirm **which enum** the column uses. A classic case: `TipoPedidoComex` is inverted relative to `LocalidadeDePedido` (0 = International / 1 = National). Some enums (such as `Chaves`) hold **configuration values**, not a 0,1,2 sequence. Values 900+ in some status enums are visual-only helpers, never stored in the database.
</Callout>
