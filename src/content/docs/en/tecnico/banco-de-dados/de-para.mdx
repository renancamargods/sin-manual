## Overview

A **De/Para** is a translation table: for each value used in CrmSin, it states the equivalent value expected by another system. In the S.I.N Implant System, De/Para tables serve mainly the **SAP S/4HANA integration** — they convert CRM records (customer, order, plant, payment terms) into the *customizing* codes that SIN's SAP actually uses.

<Callout type="atencao" title="Not a system screen">
There is no "De/Para" screen in CrmSin. These mappings live partly in the integration **code** (class `MontadorDadosClienteSap` and `PedidoCapa` rules) and partly in **database records/tables** (for example `Pedidos_OperacaoInteligente` and `Administrador_Centro`). The values below were extracted from the legacy RFC/BAPI integrator and **confirmed against the homologation database**.
</Callout>

## Order — order type and reason

The **order type** (SalesOrderType) comes from the item's Smart Operation (field "OrdemErp"), with two adjustments: a plant other than "1000" with order "ZKBB" becomes "KBB"; and "YDOA" items force the header to "YDOA".

Registered OrdemErp values: `CONSCONSIG`, `DEVCONSIG`, `DEVOLUCAO`, `ENCVD`, `KBB`, `KEB`, `OPL1`, `OPL3`, `ORB`, `REMCONSIG`, `YBEX`, `YBON`, `YDBE`, `YDEX`, `YDOA`, `YEBN`, `YEXB`, `YEXN`, `YEXP`, `YOPL`, `YRDB`, `YROB`, `YTRO`, `ZCLI`, `ZDIS`, `ZDO1`, `ZKBB`, `ZKEB`, `ZOR1`.
