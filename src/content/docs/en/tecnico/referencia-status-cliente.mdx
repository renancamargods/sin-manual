## Overview

This is a **reference** page: the full list of possible customer registration statuses, with the meaning and the typical support action. Use it to quickly look up what a status means.

<Callout type="info" title="Two approval flows coexist">
The <strong>Review/Re-analysis/Denied</strong> statuses belong to the <strong>With Ignition</strong> flow (legacy). The <strong>Awaiting Approvals</strong>, <strong>Approval Cycle Cancelled</strong> and <strong>Released New Queue</strong> statuses belong to the <strong>new queue flow</strong>. Which one applies depends on the customer queue parameter. See the flows in <a href="/en/tecnico/fluxos/cadastro-clientes-sem-ignition">Customer Registration - Without Ignition</a> and <a href="/en/tecnico/fluxos/criacao-de-cliente">With Ignition</a>.
</Callout>

<Callout type="dica" title="Rule that reopens approval">
Whenever fields that affect an area are changed, the customer <strong>goes back</strong> to awaiting that area's approval. This is defined by the <strong>Field Validation</strong> setup — detailed in the <a href="/en/tecnico/fluxos/cadastro-clientes-sem-ignition">Customer Registration - Without Ignition</a> flow.
</Callout>
