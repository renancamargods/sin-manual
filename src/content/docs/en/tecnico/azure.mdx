## Overview

This section gathers the **standards and templates** to open items in **Azure DevOps** consistently: how to write a **bug report** and how to document an **improvement/development requirement (PBI)**, always linked to the Order and with the required fields filled in.

## When to use this page

- Open a well-described **Bug**, with reproduction steps and evidence.
- Open a **PBI** (improvement or development) with a clear requirement and acceptance criteria.
- Standardize what is required in Azure DevOps before saving the item.

<Callout type="info" title="Supporting content">
This section is for people who log bugs and improvements in Azure DevOps. Use the prompt templates to generate the text and follow the step-by-step opening guide in each submodule.
</Callout>
