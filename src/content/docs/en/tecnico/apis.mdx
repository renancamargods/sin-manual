## Overview

The S.I.N Implant System talks to **several external APIs** (ERP, payment methods, credit/anti-fraud, tax, logistics and signature) and **exposes its own API** (GraphQL and REST) to the front end and to integrators. This page catalogs those integrations by purpose.

<Callout type="cuidado" title="Internal, protected content">
This page is part of the Technical Docs (password-protected). **Credentials, tokens and keys are not here** — only what each integration does. Secrets live in the environment's secure configuration.
</Callout>

## The system's own API

- **GraphQL** — the main API used by the front end (Blazor) and integrators (queries and mutations per module).
- **REST** — REST services and integration endpoints (REST Services and Integration Services), including the **received webhooks** (e.g., card payment status from Pagar.me/PayGo and the CBS assessment return).
- Call **authentication/permission** follows the [Permissions](/en/tecnico/permissoes) model.
