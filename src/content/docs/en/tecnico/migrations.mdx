## Overview

The system versions the **database structure** with Entity Framework Core **migrations**: each structural change (new table, column, index, removal) is a numbered migration, applied in order. This keeps the database in sync with the code across all environments.

## The two contexts

Migrations are split into **two contexts** (databases/domains):

<DocTable
  headers={['Context', 'What it versions', 'Migration count']}
  rows={[
    ['Administrator (SqlServer)', 'Most of the system (registrations, orders, invoicing, integrations, etc.).', '~900'],
    ['Authenticator (SqlServer)', 'Users, profiles, groups and permissions.', '~45'],

There are roughly **945 migrations** in total (the number grows with each structural change).

## Naming convention

Each migration follows the pattern:

`&lt;timestamp&gt;_Migration_&lt;Author&gt;_&lt;Description&gt;`

- **timestamp** — creation date/time (e.g., `20260827140919`), which also defines the **order** of application.
- **Author** — who created it (e.g., `LuanHora`, `LidiaBrito`, `WilliamPereira`).
- **Description** — what the migration does (e.g., `Entidade_ControleFuncionalidades`, `Melhorias_LogsExecucaoServicos`).

## How they are applied

Migrations are applied by the EF Core tooling / the deploy process (they are not applied automatically on application startup). Each migration's file pair (the migration itself + the `.Designer`) and the context's `ModelSnapshot` keep the current model state.

<Callout type="cuidado" title="Do not edit an applied migration">
A migration that already ran in some environment **must not be changed** — the correct approach is to **create a new** migration for the fix. Editing an old migration breaks the history and the sync across environments.
</Callout>

<Callout type="info" title="Where they live">
In the system repository: `CrmSin.Infra.Data.Administrador.SqlServer/Migrations` and `CrmSin.Infra.Data.Autenticador.SqlServer/Migrations`. The full list of the ~945 migrations is not shown here — check the repository for the detailed history.
</Callout>
