## Overview

This section gathers technical **database and DBA** topics of the S.I.N Implant System: how data is structured and, above all, the **value-mapping (De/Para)** tables — the mappings that translate the codes used in CrmSin into the codes expected by other systems (for example, **SAP S/4HANA**).

## When to use this page

- Understand how a value registered in the system is converted before going to an integration.
- Support the DBA, support and integration teams in checking mappings.

<Callout type="info" title="Supporting content">
This section is intended for teams responsible for configuration, database, DBA and integration. It is not required for day-to-day use of the screens.
</Callout>
