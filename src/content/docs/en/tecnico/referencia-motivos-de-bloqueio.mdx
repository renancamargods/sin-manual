## Overview

This is a **reference** page: all the blocking reasons that can appear on an order, with the responsible area and the meaning. To understand **when** each block is generated, see **[Credit Engine - Automatic Order Analysis](/en/tecnico/fluxos/motor-de-credito-analise-automatica)**.

<Callout type="info" title="Who handles the block">
Most blocks belong to the <strong>Sales Admin</strong> area (commercial policy). The <strong>Credit</strong> ones come from credit analysis / refusal. The analysis clears the previous blocks and rebuilds the list on each order submission.
</Callout>
