## Overview

This page provides a **prompt template** to generate the **requirement documentation** for an improvement/development and the **step-by-step** to open the **PBI (Product Backlog Item)** in **Azure DevOps**, linked to the Order and with all the **required fields** filled in.

The idea is always the same: **fill in the prompt → generate the documentation → paste the text into the PBI's "Description" field → fill in the required fields → save.**

## How to use (step by step)

1. Copy the template below and **fill in what is in brackets** with your feature.
2. Generate the requirement documentation (with the AI/assistant).
3. In Azure DevOps, from the **Order**, add a **Parent link of type Product Backlog Item**.
4. **Paste the generated text into the PBI's "Description" field.**
5. Fill in the **required fields** (section below) and **save**.

## Prompt template

```text
Act as a senior Product Owner (PO) / Requirements Analyst and write detailed software requirement documentation, ready to become a PBI in Azure DevOps, for the feature below.

Feature: [briefly describe what needs to be done. Ex: PDF report export button]
Business Goal: [why do it / which problem it solves. Ex: allow managers to download data for meetings]
Target Audience: [who will use it. Ex: system administrators]
Main Rules/Validations: [Ex: current month data only, generate in under 5 seconds, A4 format]

Deliver the documentation with:
- PBI Title
- Description / Context
- Acceptance Criteria (a verifiable checklist; use Given-When-Then where it makes sense)
- Business Rules and Validations
- Out of Scope (what will not be done)
- Dependencies / Impacts (affected screens, integrations, permissions)
- Technical Notes (if any)
```
