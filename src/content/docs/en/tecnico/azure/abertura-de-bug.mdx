## Overview

This page provides a **prompt template** to generate a well-structured **bug report** and the **step-by-step** to open the Bug in **Azure DevOps**, linked to the Order (parent Work Item) and with all the **required fields** filled in.

The idea is always the same: **fill in the prompt → generate the text → paste the text into the Bug's "Repro Steps" field → fill in the required fields → save.**

## How to use (step by step)

1. Copy the template below and **fill in what is in brackets** with your problem.
2. Generate the report text (with the AI/assistant).
3. In Azure DevOps, from the **Order**, add a **Child link of type Bug**.
4. **Paste the generated text into the Bug's "Repro Steps" field.**
5. Fill in the **required fields** (section below) and **save**.

## Prompt template

```text
I need you to create a bug report for Azure DevOps regarding the following problem: [describe the problem].

Structure the report exactly in the sections below:

1. Title — short, objective summary of the error (what + where).
2. Error Description — what goes wrong, on which screen/module, since when and how often (always / sometimes / specific case).
3. Steps to Reproduce — the exact numbered sequence to reproduce it, with sample data, profile/user and environment (HML or Production).
4. Expected Behavior — what should happen if it were correct.
5. Possible Fix (Technical Suggestion) — a hypothesis of the cause and a suggested fix, if any.
6. Evidence — screenshots, error message, logs, order/record ID, date and time.

Write it clearly and objectively, ready to paste into Azure DevOps.
```
