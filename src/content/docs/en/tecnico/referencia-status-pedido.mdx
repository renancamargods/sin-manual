## Overview

This is a **reference** page: the full list of possible order statuses, with the meaning and the typical support action. To understand **why** an order stopped in review, see **[Credit Engine - Automatic Order Analysis](/en/tecnico/fluxos/motor-de-credito-analise-automatica)** and **[Blocking Reasons](/en/tecnico/referencia-motivos-de-bloqueio)**.

<Callout type="dica" title="'Error' statuses need escalation">
Statuses starting with <strong>Error</strong> (integration, PIX, card, invoicing, mixed payment) usually indicate a technical failure — check the logs and escalate to the responsible team.
</Callout>
