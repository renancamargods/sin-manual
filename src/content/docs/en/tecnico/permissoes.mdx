## Overview

This page brings together information about how permissions control what each user can see and do in the S.I.N Implant System. Permissions are grouped into access profiles and assigned to users.

## When to use this page

- Understand how a permission grants access to a screen or action.
- Support the definition of access profiles.
- Look up the permissions related to each routine.

<Callout type="info" title="Where to configure">
User profiles and permissions are managed in the Authenticator module, through the Profile and User screens.
</Callout>
