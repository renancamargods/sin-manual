## Overview

Rules the **User** registration requires to save, derived from the system validator. Some depend on the **authentication method** and on whether the user is **generic**.

## Required

<DocTable
  headers={['Field', 'Rule']}
  rows={[
    ['Name', 'Required; up to 150 characters.'],
    ['E-mail (login)', 'Required; up to 150 characters.'],
    ['Active', 'Required.'],
    ['Authentication Method', 'Required.'],
    ['System User', 'Required.'],
  ]}
/>

## Initial password

<DocTable
  headers={['Field', 'Rule']}
  rows={[
    ['Initial Password', 'Required for a new user with password authentication (does not apply to Active Directory or on edit).'],
    ['Repeat Password', 'Must match the Initial Password.'],
  ]}
/>

## Conditionals

<DocTable
  headers={['Case', 'Rule']}
  rows={[
    ['Active Directory (or Both)', 'The "Windows Login" becomes required; the initial password is waived.'],
    ['Generic user', 'Waives E-mail, Authentication Method, System User and password.'],
  ]}
/>

## Length limits

<DocTable
  headers={['Field', 'Maximum']}
  rows={[
    ['Phone', '15 characters.'],
    ['Registration Number', '100 characters.'],
  ]}
/>
