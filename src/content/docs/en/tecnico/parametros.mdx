## Overview

This page brings together the general system configuration parameters, used to adjust behaviors that affect different modules.

## When to use this page

- Look up the available general parameters.
- Understand the impact of a parameter before changing it.

<Callout type="cuidado" title="Broad impact">
Changes to general parameters may affect the behavior of several modules at the same time. Assess the impact before changing.
</Callout>
