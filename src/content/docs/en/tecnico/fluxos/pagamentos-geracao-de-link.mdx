## Overview

After an order is approved, the system decides **how to charge**: send it straight to SAP (when it is already paid or there is no online charge), **generate a payment link** (PIX or card), **send a charge to the card terminal**, or **handle a mixed payment**. This page describes the charge generation and the **gateway** integration: **PIX** via **EFI (GerenciaNet)** and **card/card terminal** via **Pagar.me**.

For the payment form and terms rules inside the order, see [Order Process — Payment](/en/tecnico/fluxos/processo-do-pedido-pagamento). To combine more than one form, see [Mixed Payment](/en/tecnico/fluxos/pagamento-misto).

## PIX — EFI (GerenciaNet)

- The system **generates the PIX charge** in EFI and provides the **QR Code / copy-and-paste code**.
- It tracks the payment by **query** (and reconciliation) — when the PIX is paid, the order proceeds to the SAP integration.
- The charge can be **canceled** if not paid.

<Callout type="info" title="PIX key">
The PIX charge uses the configured **key**. The possible types (`TipoDeChavePix`) are: **CPF**, **CNPJ**, **email**, **mobile** and **random**.
</Callout>

## Card and Card Terminal — Pagar.me

- **Card link:** the system generates a **payment link** in Pagar.me and provides it to the customer.
- **Card terminal:** the system **sends the charge** to a terminal registered as a **Payment Terminal** (Administrador module).
- **Return:** Pagar.me confirms the payment by **webhook** (automatic return); the system also queries the status when needed.
- **Notifications:** the customer can be **notified** by email and WhatsApp with the link/charge.
- The charge can be **canceled** in Pagar.me when the order is canceled.

## Relationship with other processes

- **Payment in the order:** the form/terms rules are in [Order Process — Payment](/en/tecnico/fluxos/processo-do-pedido-pagamento).
- **Mixed payment:** combining forms on the same order — see [Mixed Payment](/en/tecnico/fluxos/pagamento-misto).
- **SAP integration:** once the payment is confirmed, the order proceeds to the [SAP integration chain](/en/tecnico/fluxos/integracao-sap-os-quatro-fluxos).
- **Value Mapping:** `FluxoPosAprovacaoDePedido` and `TipoDeChavePix` are in [Database → Value Mapping](/en/tecnico/banco-de-dados/de-para).

## Common problems

- **Link won't generate:** check the order's payment form and the gateway configuration (PIX key / Pagar.me credentials).
- **PIX doesn't clear:** the payment is confirmed by query/reconciliation; if paid and not cleared, check the PIX reconciliation.
- **Card terminal doesn't get the charge:** confirm the Payment Terminal registered in Administrador.
- **Paid but the order doesn't move:** check the return (webhook) and the status up to the SAP integration.
