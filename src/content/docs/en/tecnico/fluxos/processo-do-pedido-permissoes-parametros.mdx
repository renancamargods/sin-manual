## Overview

This is **Part 6** (final) of the [Order Process](/en/tecnico/fluxos/processo-do-pedido). Here we gather the "behind the scenes" of the flow: the **permissions** that control who accesses the screen and performs each action, and the system **parameters** that adjust the order behavior (domestic/international, bonus, payment methods, deadlines, credit, email groups, Ignition).

It is the reference page for **support** and **configuration** — most of this content is technical.

<Callout type="cuidado" title="Technical content">
Changing permissions or parameters changes the system behavior for everyone. Only make changes when you know the effect and, preferably, with support from the technical team.
</Callout>

## Permissions

Access to the **Order** screen and to each action (create, submit, approve) is controlled by **permissions**. In S.I.N, permissions are organized by **URL/screen**, assigned to user **Profiles** and **Groups** (the **Authenticator** module).

<DocTable
  headers={['What it controls', 'How it works', 'Where to configure']}
  rows={[
    ['Access to the Order screen', 'The screen requires the corresponding permission; without it, the user cannot open it.', 'Authenticator → Profile / Group / URL.'],
    ['Actions on the order (create, submit, etc.)', 'Each action may require a specific permission.', 'Authenticator → Profile.'],
    ['Who approves each step', 'Not a fixed permission: the approver comes from the Approval Rule.', 'Approvals → Approval Rule (see the Order Approval flow).'],
    ['Credit profiles', 'Profiles used in the credit review (domestic and foreign trade).', 'Parameter: PerfilCredito / PerfilCreditoComex.'],
    ['Ignition profile', 'Profile used by the Ignition queue.', 'Parameter: IdPerfilIgnition.'],
  ]}
/>

<Callout type="info" title="Permission x Approval">
One thing is **being able to open/use** the screen (Authenticator permission); another is **who approves** the order — that is defined in the **Approval Rule**, not a fixed permission. See the <em>Order Approval - Without Ignition</em> flow.
</Callout>
