## Overview

**HandsOn Requests** register and handle the **training logistics** requests — a **professor**, the shipment of **material** or a **factory visit** — tied to the **courses** offered. It is the process that organizes the support needed for a training to happen.

## When to use this flow

- **Request a professor** for a course (HandsOn Professor).
- **Request material** for a training.
- **Request a factory visit**.

## Request type and reason

The request is of the type **"HandsOn Professor Requests"** (`TipoOcorrenciaHandsOn`) and starts in the situation **"Opening"** (`SituacaoOcorrenciaHandsOn`). The **reason** (`MotivoOcorrenciaHandsOn`) defines what is requested:

  ]}

## Course types

The request is tied to a course, whose type (`TipoCursoHandsOn`) can be:

## Request structure

The screen gathers the **Requests** and the associated **Products** (training material/kit), letting you track what was requested for each course.
