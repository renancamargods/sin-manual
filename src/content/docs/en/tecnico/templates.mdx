## Overview

This page brings together information about the templates reused by the system — for example, in documents, messages and labels. Using templates helps keep a standard and reduce rework.

## When to use this page

- Look up which templates are available.
- Understand where each template is used.
- Support creating or adjusting a template together with the responsible area.

<Callout type="info" title="Supporting content">
This section is aimed at teams responsible for configuring and standardizing documents and messages.
