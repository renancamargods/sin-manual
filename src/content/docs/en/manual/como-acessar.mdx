## Overview

Access to the S.I.N Implant System is done with a username and password registered by the system administrator. Each user has an access profile, which defines the modules and screens they can use.

## Before you start

- Have at hand the username and password provided by the company.
- Check whether you already have an access profile registered. Otherwise, contact the system administrator.
- Use an up-to-date browser for the best compatibility.

## Main flows

1. Go to the system address provided by the company.
2. Enter the registered username and password.
3. Click **Sign in**.
4. On the first access, the system may ask you to change the initial password.

<Callout type="dica" title="Forgot your password?">
Use the password recovery option on the login screen. A reset link will be sent to the registered email.
</Callout>
