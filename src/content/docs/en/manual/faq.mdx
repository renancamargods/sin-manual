## About permissions

<FaqAccordion
  items={[
    { question: 'What does it mean for a screen to "require permission"?', answer: 'It means that, besides accessing the system, the user needs a specific permission enabled in their profile to open or use that screen.' },
    { question: 'Who grants permissions?', answer: 'The system administrator, through the Profile and User screens in the Authenticator module.' },
  ]}
/>

<FaqAccordion
