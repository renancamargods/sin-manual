## Visão geral

O acesso ao S.I.N Implant System é feito com um usuário e uma senha cadastrados pelo administrador do sistema. Cada usuário tem um perfil de acesso, que define quais módulos e telas ele pode utilizar.

## Antes de começar

- Tenha em mãos o usuário e a senha fornecidos pela empresa.
- Verifique se você já possui um perfil de acesso cadastrado. Caso contrário, procure o administrador do sistema.
- Utilize um navegador atualizado para melhor compatibilidade.

## Fluxos principais

1. Acesse o endereço do sistema informado pela empresa.
2. Informe o usuário e a senha cadastrados.
3. Clique em **Entrar**.
4. No primeiro acesso, o sistema pode solicitar a troca da senha inicial.

<Callout type="dica" title="Esqueceu a senha?">
Utilize a opção de recuperação de senha na tela de login. Um link de redefinição será enviado para o e-mail cadastrado.
</Callout>
