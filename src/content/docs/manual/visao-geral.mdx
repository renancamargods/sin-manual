## Visão geral

O S.I.N Implant System é organizado por **módulos**. Cada módulo reúne as telas e rotinas relacionadas a um mesmo tema — por exemplo, o módulo Clientes concentra os cadastros ligados aos clientes, e o módulo Pedidos concentra tudo relacionado a pedidos de venda.

Essa organização ajuda a encontrar rapidamente onde cadastrar, consultar ou acompanhar uma informação, mesmo sem saber o nome exato da tela.

<Callout type="info" title="Acesso por perfil">
Nem todos os usuários enxergam todos os módulos. O que aparece disponível depende do perfil de acesso configurado para o seu usuário.
</Callout>

## Como navegar

- Use o **menu lateral** para abrir um módulo e ver suas telas.
- Use a **busca** no topo da página para localizar uma tela pelo nome.
- Cada tela indica, logo no início, o módulo ao qual pertence e se exige permissão específica.
